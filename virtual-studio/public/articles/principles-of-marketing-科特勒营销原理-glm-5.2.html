// 关于第十七版

第十七版《营销原理》在保留经典营销概念的同时，融入了客户参与营销、移动与社交媒体、大数据与新营销分析、物联网、全渠道营销与零售、客户共创与赋权、实时客户聆听、品牌社区构建、营销内容策展与原生广告、B2B 社交媒体与社交销售、分层与动态定价、消费者隐私、可持续发展、全球营销等前沿议题。

五大客户价值与参与主题
THEME 01

为客户创造价值以从客户那里捕获价值

出色的营销公司理解市场与客户需求，设计创造价值的营销战略，开发整合的营销程序来参与客户并交付价值与满意度，建立强有力的客户关系与品牌社区。作为回报，他们以销售、利润和客户资产的形式从客户那里捕获价值。

THEME 02

客户参与与数字社交媒体

客户参与营销旨在让品牌成为消费者对话与生活有意义的一部分——通过直接且持续的客户卷入，塑造品牌对话、品牌体验与品牌社区。新数字工具使品牌与消费者的连接更深度、更互动。

THEME 03

建设与管理强有力的价值创造品牌

定位良好且具有强品牌资产的品牌，是构建客户价值与盈利客户关系的基础。当今营销者必须强有力地定位品牌并加以管理，以创造有价值的品牌体验。

THEME 04

测量与管理营销回报

"营销问责"——测量与管理营销投资回报率——已成为战略营销决策的关键部分。营销者必须证明其营销支出正在被良好使用。

THEME 05

全球范围的可持续营销

满足当前消费者与企业需求，同时保护或增强后代满足其需求的能力。营销者必须以可持续的方式在全球范围内营销品牌。

CASE

阿联酋航空 Emirates

"Hello Tomorrow"运动将全球旅行品牌重塑为生活方式选择，连接全球主义者与不同文化。品牌价值估计 77 亿美元，成为全球最有价值航空公司品牌。

CHAPTER 01 · 第一章

营销：创造客户价值与参与

// 1.1 营销的定义

什么是营销？

营销远不止"销售与广告"。从最广义看，营销是通过与他人创造和交换价值来获得所需所求的社会与管理过程。在更窄的商业语境中，营销是公司参与客户、建立强客户关系、为客户创造价值以便从客户那里捕获价值作为回报的过程。

营销的目的是让销售变得不必要。 — Peter Drucker · 管理学者

营销的双重目标：通过承诺卓越价值吸引新客户；通过交付价值和满意来留住并增长现有客户。

FIG 1.1 · 营销过程五步模型：前四步为客户创造价值，第五步从客户那里捕获价值作为回报。
// 1.2 理解市场与客户需求 · 五大核心概念

市场的五个核心概念

CORE 01

需要、欲望与需求

需要(Needs) 是感到剥夺的状态——基本生理、社会与个人需要。欲望(Wants) 是需要经文化与个性塑造后的形式。需求(Demands) 是有购买力支持的欲望。

CORE 02

市场提供物

产品、服务、信息或体验的组合，用于满足需要或欲望。营销近视症(Marketing Myopia) 是只关注具体产品而忽视客户底层需要的错误。

CORE 03

客户价值与满意度

客户对市场提供物所交付价值与满意度的期望形成购买行为。期望过低难以吸引买家；期望过高则导致失望。关键在于恰当设定期望并交付超越期望。

CORE 04

交换与关系

交换是从某人那里获得所需对象并提供某物作为回报的行为。营销包括创建、维护、增长与目标受众之间 desirable 的交换关系。

CORE 05

市场

市场是某种产品或服务的实际与潜在买家的集合。这些买家共享某种可由交换关系满足的需要或欲望。

EXTRA

客户管理 = 需求管理

营销管理在本质上是客户管理和需求管理。营销者不再问"我们如何影响客户？"，而是问"客户如何影响我们？"以及"客户如何相互影响？"

// 1.4 管理客户关系 · 捕获客户价值

客户关系管理 (CRM) 与客户资产

客户关系管理是通过交付卓越客户价值与满意度来建立和维护盈利客户关系的总体过程。其关键构建块是客户感知价值(Customer-Perceived Value) 与客户满意度(Customer Satisfaction)。

CONCEPT

客户终身价值 (CLV)

客户在一生光顾中所有购买的整个流的价值。例如，Stew Leonard's 估算每位不满意的客户流失等于损失 $50,000；Lexus 估算单一忠诚客户终身价值超过 $600,000。

CONCEPT

客户份额 (Share of Customer)

公司在其产品类别中获得的客户购买份额。银行想要"钱包份额"，超市想要"胃份额"，汽车公司想要"车库份额"，航空公司想要"旅行份额"。

CONCEPT

客户资产 (Customer Equity)

公司所有当前与潜在客户的客户终身价值之总和。它是公司客户基础未来价值的衡量——比当前销售或市场份额更好地反映未来。

CONCEPT

客户参与营销

通过直接且持续的客户卷入塑造品牌对话、品牌体验与品牌社区，使品牌成为消费者对话与生活有意义的一部分。从"营销品牌给消费者"转向"与消费者共建品牌"。

// 1.5 变化的营销图景 · 五大趋势

正在重塑营销的五大力量

FORCE 01

数字时代

在线、移动与社交媒体营销。物联网(IoT) 让一切互联——全球 33 亿人在线，64% 美国成年人拥有智能手机。营销者通过网站、社交、移动广告与应用、在线视频、电邮、博客等数字平台随时随地参与消费者。

FORCE 02

变化的经济环境

大衰退后消费者重新审视消费价值观。即使收入回升，节俭已成为新常态——更少购买、更多使用优惠券、更多储蓄。营销者强调价值主张中的"价值"维度。

FORCE 03

非营利营销增长

学院、医院、博物馆、交响乐团甚至教堂都大量采用营销。例如 St. Jude 儿童研究医院每年筹款超 10 亿美元，WWF 的 #LastSelfie Snapchat 活动三天完成月度筹款目标。

FORCE 04

快速全球化

麦当劳每天在 100 多国服务 7000 万顾客，68% 营收来自美国之外；耐克在 190 国营销，非美销售占 52%。营销者必须以全球视角审视行业、竞争与机会。

FORCE 05

可持续营销

社会与环境责任成为商业核心议题。Patagonia、Timberland、Method、Ben & Jerry's 等践行"关怀资本主义"，将社会与环境责任融入使命与价值声明。

CASE

Oreo 实时营销

2013 超级碗停电 34 分钟，Oreo 一条"You can still dunk in the dark"推文获得比其豪华广告更多的关注——成为实时营销经典案例。被誉为"赢得停电碗的品牌"。

// 2.4 营销战略与营销组合

营销组合 4P 与客户视角的 4A

营销战略由四步组成：市场细分(Segmentation)、目标市场(Targeting)、差异化(Differentiation)、定位(Positioning)。然后公司设计由 4P 构成的整合营销组合。

P 01

Product 产品

公司向目标市场提供的商品与服务组合。品种、质量、设计、特性、品牌名、包装、服务。

P 02

Price 价格

客户为获得产品必须支付的金额。标价、折扣、折让、付款期限、信用条款。

P 03

Place 渠道

使产品可被目标消费者获得的公司活动。渠道、覆盖、地点、库存、运输、物流。

P 04

Promotion 促销

传达产品优点并说服目标客户购买的活动。广告、人员推销、销售促进、公关、数字营销。

客户视角的 4A 框架

从买方视角，4P 可重新表述为 4A：

A 01

Acceptability 可接受性

产品超出客户期望的程度。（对应 Product）

A 02

Affordability 可负担性

客户愿意且能够支付价格的程度。（对应 Price）

A 03

Accessibility 可达性

客户能轻易获得产品的程度。（对应 Place）

A 04

Awareness 知晓度

客户被告知、被说服、被提醒的程度。（对应 Promotion）

// 2.5 管理营销努力与营销投资回报率

SWOT 分析 · 营销管理职能 · 营销 ROI

营销管理包含四个职能：分析(SWOT)、规划、实施、控制。

FIG 2.7 · SWOT 分析：将公司优势匹配到环境中吸引人的机会，同时消除或克服劣势并最小化威胁。
营销投资回报率 (Marketing ROI)

营销 ROI = 营销投资的净回报 ÷ 营销投资成本。它衡量营销活动产生的利润。然而营销 ROI 难以测量——参与度、广告、品牌建设影响不易转化为美元回报。

越来越多公司使用客户中心指标：客户获取、客户参与、客户体验、客户留存、客户终身价值、客户资产。这些指标既捕捉当前也捕捉未来的绩效。

// 3.1 微观环境 · 公司价值传递网络

微观环境的六大参与者

微观环境由接近公司、影响其服务客户能力的参与者组成。营销成功要求与这些参与者建立关系。

五类客户市场：消费者市场、业务市场、转售市场、政府市场、国际市场。

// 3.3 人口与经济环境

人口结构变化 · 四代同堂

美国最重要的人口趋势是人口年龄结构的变化——主要由于出生率下降与预期寿命延长。

GEN · 1946-1964

婴儿潮一代

7800万人，美国历史上最富有的一代。占人口26%却控制70%可支配收入。仍在积极消费——80%奢侈品旅行支出、增长最快的在线购物人群。

GEN · 1965-1976

X 世代

4900万人，务实的购物者，重视体验胜过拥有。重研究、重质量、对营销说教不敏感。占人口不到1/4却获29%总收入。

GEN · 1977-2000

千禧一代 (Y)

8300万人，比婴儿潮更大。数字化原住民。节俭、实用、连接、移动、不耐烦。寻求真实性与塑造品牌体验的机会。

GEN · 2000+

Z 世代

8200万人，每年自有支出440亿美元，影响6000亿美元家庭支出。"数字DNA"——智能手机、平板、社交媒体视为理所当然。研究后购买。线上与线下无缝融合。

经济环境 · 节俭新常态

大衰退后，即使收入回升，节俭已成为新常态——更少购买、更多使用优惠券、更多储蓄。价值营销成为关键词。即使奢侈品牌也强调价值——Tiffany 推出 $100-500 的"时尚珠宝"线，占其销售额的1/4。

收入分布两极化：前5% 美国收入者获得22%调整后总收入，前20%获得51%；底部40%仅获得11%。形成双层市场。

// 3.4 自然 · 技术 · 政治 · 文化

四类环境的关键趋势

NATURAL · 自然

三大趋势

原材料短缺：到2030年全球1/3人口将缺水。污染增加：化学与核废料、海洋汞含量、不可降解包装。政府干预增加：EPA等机构加强管制。环境可持续运动兴起——Nike 将5400万英镑废料转为高性能材料。

TECHNOLOGICAL · 技术

最具戏剧性的力量

RFID、GPS、蓝牙技术已改变零售。Disney MagicBand 通过 RFID 手环让游客"开腕"进入乐园、购物、解锁酒店房间。新技术替代旧技术——晶体管淘汰真空管，数码摄影淘汰胶片，流媒体冲击DVD。

POLITICAL · 政治

立法的三项目的

保护公司相互之间(反垄断)；保护消费者免受不公平商业行为(虚假广告、误导包装)；保护社会利益免受无约束商业行为(环境、安全)。事业相关营销 (Cause-Related Marketing) 兴起——Warby Parker "买一捐一"。

CULTURAL · 文化

核心价值观 vs 次价值观

核心价值观持久（婚姻、努力工作），次价值观可变（早婚还是晚婚）。文化视角六个维度：人们对自己、他人、组织、社会、自然、宇宙的看法。如 Annie's Homegrown 主张"对地球永远友善"。

三种公司：让事情发生的、看着事情发生的、 wondering 发生了什么的。 — 营销环境响应格言

响应环境的两种姿态：被动接受(视为不可控因素，避免威胁、利用机会) 或主动塑造(开发战略改变环境，如 Ford Model T、Apple iPhone、Google 搜索、Amazon 在线市场)。聪明营销者尽可能采取主动而非被动姿态。

05
TOOLBOX · 理性防线

营销者的工具箱·框架速查

从本书前三章提炼的核心工具与框架。每个营销者在面对决策时可调用以下防线：

// TOOL 01
五步营销过程模型

理解市场 → 设计战略 → 构建方案 → 建立关系 → 捕获价值。前四步创造价值，第五步捕获价值。

// TOOL 02
五大核心市场概念

需要 / 欲望 / 需求 · 市场提供物 · 价值与满意度 · 交换与关系 · 市场。

// TOOL 03
五种营销管理导向

生产 / 产品 / 推销 / 营销 / 社会营销。从由内向外转向由外向内。

// TOOL 04
营销近视症检查

问自己：客户真正需要的是什么？四分之一英寸的"孔"还是"钻头"？产品只是解决问题的工具。

// TOOL 05
客户关系分组矩阵

陌生人 / 蝴蝶 / 藤壶 / 真朋友——按盈利能力与忠诚度分类，采取差异化管理策略。

// TOOL 06
客户资产公式

客户资产 = 所有客户终身价值之和。比当前销售或市场份额更能反映未来。

// TOOL 07
战略规划四步

定义使命 → 设定目标 → 设计业务组合 → 制定职能计划。使命应以市场而非产品定义。

// TOOL 08
BCG 增长份额矩阵

明星 / 现金牛 / 问号 / 瘦狗。从现金牛取现投入明星与问号，审视瘦狗。四策略：Build / Hold / Harvest / Divest。

// TOOL 09
产品/市场扩张网格

市场渗透 / 市场开发 / 产品开发 / 多元化。系统化识别增长机会。

// TOOL 10
营销战略四要素

STDP：Segmentation 细分 → Targeting 目标 → Differentiation 差异化 → Positioning 定位。

// TOOL 11
4P + 4A 双视角

卖方4P：Product / Price / Place / Promotion。买方4A：Acceptability / Affordability / Accessibility / Awareness。先4A后4P。

// TOOL 12
SWOT 形势分析

Strengths / Weaknesses (内部) + Opportunities / Threats (外部)。目标：将优势匹配机会，消除劣势，最小化威胁。

// TOOL 13
营销管理四职能

分析 → 规划 → 实施 → 控制。其中控制包括运营控制 (年度计划) 与战略控制 (基本策略匹配)。

// TOOL 14
营销 ROI 测算

营销 ROI = (营销投资净回报) ÷ (营销投资成本)。客户中心指标：获取、参与、体验、留存、CLV、客户资产。

// TOOL 15
价值传递网络

公司 + 供应商 + 中介 + 客户形成的网络。竞争不再是公司之间，而是价值传递网络之间。

// TOOL 16
微观/宏观环境扫描

微观六方：公司、供应商、中介、竞争者、公众、客户。宏观六力：人口、经济、自然、技术、政治、文化。

// TOOL 17
世代分群速查

婴儿潮 (1946-64) · X世代 (1965-76) · 千禧 (1977-2000) · Z世代 (2000+)。各世代价值观、消费习惯、媒介偏好迥异。

// TOOL 18
主动 vs 被动环境响应

被动：分析环境并设计避免威胁、利用机会的战略。主动：开发战略改变环境——lobbying、媒体事件、社交舆论、诉讼。
