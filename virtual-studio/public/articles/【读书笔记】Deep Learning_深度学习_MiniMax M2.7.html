    1.1 本章核心论点

    "深度学习是让计算机通过经验学习，以概念的分层结构来理解世界的方法。"

    1.2 人工智能的经典困境：形式化知识的局限

    传统AI方法（知识库方法）的失败

    早期的AI系统试图将人类知识手工编码为形式语言（如Cyc项目）。这种方式面临根本性困难：

    • 规则复杂度爆炸：描述"人不会通电"这一常识，需要同时处理无数例外情境（电动剃须刀使用中的人、手握电线的人……）
    • 知识获取瓶颈：人类专家无法穷尽描述真实世界所需的所有规则
    • 脆弱性：系统无法处理规则未覆盖的边界情况
    
# 知识工程方法的伪代码示例（失败案例）
if entity.contains("electrical_parts"):
    if entity.name != "FredWhileShaving":
        raise inconsistency("Fred应该不是人？")

    芙蕾妲（Fred）悖论：Cyc系统无法理解"Fred早晨刮胡子"的故事——因为Fred手持电动剃须刀，系统推断"FredWhileShaving包含电气零件"，而人没有电气零件，产生矛盾。

    1.3 表示学习（Representation Learning）

    核心思想

    关键洞察：与其手工设计特征，不如让算法自动从数据中学习表示。

    传统机器学习高度依赖特征工程（Feature Engineering）——人类专家需要为每种任务精心设计特征：

    任务手工特征问题
    图像分类设计HOG/SIFT特征需要领域知识，无法泛化
    语音识别设计MFCC特征丢失大量声学信息
    医疗诊断医生报告中的关键词受限于医生表达能力

    表示学习的优势：

    • 可以发现手工难以设计的复杂特征
    • 能够快速适应新任务（几分钟到数月 vs 手工设计的数十年）
    • 端到端优化，消除人工瓶颈

    自编码器（Autoencoder）

    表示学习的典型例子：

    • 编码器（Encoder）：将原始输入转换为新表示
    • 解码器（Decoder）：将新表示还原为原始格式
    • 训练目标：使还原后的内容尽可能保留原始信息
    • 额外约束：迫使新表示具有良好性质（如低维、稀疏、独立因子等）

    1.4 深度学习：层次化表示

    "深度"的含义

    深度学习通过组合简单概念来构建复杂概念。以图像识别为例：

    
输入像素（原始数据）
    ↓ 第1层：边缘检测（Edge detection）
    ↓ 第2层：轮廓和角落（Corners & contours）
    ↓ 第3层：物体部件（Object parts）
    ↓ 第4层：完整物体（Car / Person / Animal）

    两种理解"深度"的视角

    视角定义例子
    计算图深度从输入到输出经过的最多计算步骤数MLP的层数
    概率建模图深度概念之间解释关系的层数因子图的层数

    两种视角不必等价：在深度概率模型中，一个概念层可能需要多次迭代才能 refinement。

    深度学习的两个视角

    视角一：表示学习

    深度学习 = 学习好的表示 + 学习从表示到输出的映射

    视角二：学习多步计算机程序

    • 每层的激活值相当于计算机的内存状态
    • 后续指令可以引用早期指令的结果（类比递归/循环）
    • 状态信息不仅编码输入的解释，还存储执行"程序"的计数器/指针

    1.6 三次发展浪潮（历史回顾）

    第一波：控制论（Cybernetics，1940s-1960s）

    关键里程碑：

    • 1943：McCulloch-Pitts神经元模型——首个形式化神经元
    • 1949：Hebb规则（Hebbian learning）——"一起放电的神经元会连接在一起"
    • 1958：感知器（Perceptron）——首个能学习的神经元模型（Rosenblatt）
    • 1960：ADALINE——能预测实数值的线性模型（Widrow & Hoff）

    代表模型：

    
f(x, w) = x₁w₁ + x₂w₂ + ... + xₙwₙ

    权重由人类设定（或简单学习规则调整）。

    衰落原因：Minsky & Papert（1969）证明感知器无法学习XOR函数，线性模型的天花板明显。

    第二波：连接主义（Connectionism，1980s-1995）

    关键概念：

    ① 分布式表示（Distributed Representation）

    每个输入由多个特征共同表示；每个特征参与多个不同输入的表示。

    举例：

    方法表示方式神经元数量
    局部表示（One-hot）红色卡车=神经元1，绿色汽车=神经元2，...需要k×n个神经元
    分布式表示3个神经元描述颜色 + 3个神经元描述物体只需6个神经元

    分布式表示使模型能够泛化到未见过的组合——"红色鸟类"可能从未出现在训练集中，但模型已学会"红色"和"鸟类"各自的概念。

    ② 反向传播算法（Backpropagation）

    • Rumelhart et al.（1986）：成功训练带有内部表示的深层神经网络
    • LeCun（1987）：将BP用于卷积网络训练
    • 局限性：梯度消失/爆炸问题限制了深度；1990年代逐渐失宠

    ③ 序列建模的早期突破

    • Hochreiter（1991）：识别长序列建模的数学困难（梯度消失）
    • Hochreiter & Schmidhuber（1997）：LSTM（长短期记忆网络）——解决长程依赖问题

    衰落原因：

    • 风险投资期望不切实际
    • SVM等核方法崛起
    • 计算资源不足（直到2006年深度网络仍被认为"难以训练"）

    第三波：深度学习（2006-至今）

    突破时刻：Geoffrey Hinton（2006）——深度信念网络（DBN）可通过逐层贪心预训练（greedy layer-wise pretraining）有效训练。

    关键推动因素：

    因素影响
    数据规模爆炸MNIST→ImageNet→...数据集从万级增长到亿级
    硬件进步GPU并行计算使大规模训练成为可能
    算法改进更好的激活函数、初始化方法、正则化
    软件生态Theano→TensorFlow→PyTorch

    现代特点：

    • 深度模型在视觉、语音、NLP任务上超越人类
    • 从"无监督预训练+监督微调"转向"直接大规模监督学习"
    • 迁移学习（Transfer Learning）广泛应用

    1.7 历史给我们的教训（批判性思考）

    "深度学习研究者更倾向于引用大脑作为灵感来源，但不应将深度学习视为模拟大脑。"

    常见误解纠正：

    误解真相
    深度学习 = 模拟大脑深度学习从神经科学中获得灵感，但现代模型与生物神经元的计算完全不同
    深度学习是全新发明核心算法（BP、SGD、LSTM）早在1980-1990年代就存在
    深度学习不需要领域知识架构设计、特征工程（预处理）、归纳偏置仍需专业知识

    神经科学的局限性：

    • 我们对大脑的了解远不够指导工程实践
    • 哺乳动物大脑的算法原理尚未被破解
    • "整脑模拟"（如Blue Brain项目）在可预见的未来不现实
    • 强化学习研究表明：单一算法解决多任务的假设有一定神经科学依据（"ferret视觉皮层学会听觉任务"实验）

    深度学习的多学科来源：

    
深度学习 = 神经科学（灵感）
        + 应用数学（线性代数/优化/概率）
        + 统计学（推断/泛化）
        + 计算机科学（算法/硬件）
        + 认知心理学（表示/概念）

    Chapter 2: Linear Algebra（线性代数）

    2.1 本章核心目标

    线性代数是深度学习的数学骨架。所有深度学习模型最终都归结为大规模矩阵运算——参数以矩阵/向量存储，前向传播是矩阵乘法，反向传播是矩阵求导。

    2.2 基础对象

    2.2.1 标量（Scalar）、向量（Vector）、矩阵（Matrix）、张量（Tensor）

    对象维度记号例子
    标量0维x ∈ R学习率 η = 0.01
    向量1维x ∈ Rⁿ输入特征 x ∈ R¹²⁸
    矩阵2维A ∈ Rᵐˣⁿ权重 W ∈ R⁵¹²ˣ²⁵⁶
    张量n维A ∈ Rⁿ¹ˣⁿ²ˣ...ˣⁿᵏ图像张量 (H, W, C)

    广播（Broadcasting）：NumPy风格的逐元素操作扩展规则，是深度学习框架的标配。

    2.3 矩阵运算核心

    2.3.1 矩阵乘法

    
# 深度学习中最常见的操作
# 前向传播：Z = XW + b
# 或 Y = Wᵀx + b（逐样本形式）

C = A B  # A∈Rᵐˣᵏ, B∈Rᵏˣⁿ → C∈Rᵐˣⁿ
# 不满足交换律：AB ≠ BA
# 满足结合律：(AB)C = A(BC)

    2.3.2 逐元素运算（Hadamard乘积）

    
# Gated mechanisms（如LSTM中的门控）
g = sigmoid(W_g * x)
C_new = g  C_old + (1-g)  C_candidate

    2.4 线性组合、生成子空间、线性相关性

    关键概念

    线性组合：

    
Span(A) = {c₁v₁ + c₂v₂ + ... + cₙvₙ | cᵢ ∈ R}

    列空间（Column Space）：矩阵A的列向量张成的空间。

    线性相关与生成子空间：

    • 如果至少一个列向量可以表示为其他列向量的线性组合 → 线性相关
    • 线性无关列向量的最大数量 = 矩阵的秩（Rank）

    批判性思考：秩亏（Rank Deficiency）是深度学习中的实际问题吗？

    在传统统计学习中，秩亏（特征数>样本数）导致奇异矩阵不可逆。深度学习中情况不同——由于过参数化（overparameterization），神经网络通常具有"full rank"的表达能力，但这也带来了冗余和优化困难。Lottery Ticket Hypothesis（彩票假设）认为：随机初始化的网络中存在"中奖彩票"子网络，无需训练即可表现良好。

    2.5 范数（Norms）

    范数是"长度"的数学抽象。深度学习中用于正则化（Regularization）和梯度裁剪（Gradient Clipping）。

    2.5.1 Lᵖ 范数

    
║x║ₚ = (Σᵢ|xᵢ|ᵖ)^(1/p)  for p ≥ 1

    常用范数对比

    范数公式深度学习应用特性
    L¹ΣxᵢLasso正则化，促进稀疏性对异常值较鲁棒
    L²（欧氏）√(Σxᵢ²)权重衰减（Ridge），梯度范数对大值惩罚重
    L∞（切比雪夫）maxxᵢ梯度裁剪，Wasserstein距离仅惩罚最大分量
    Frobenius√(ΣᵢⱼAᵢⱼ²)矩阵范数，正则化矩阵的"L²范数"

    2.5.2 深度学习中的正则化直觉

    
# L2正则化 = 权重衰减
# 损失函数添加 λ * ||W||²
# 梯度下降：W ← W - η(∇W + 2λW) = (1 - 2λη)W
# 权重被持续衰减向零

    批判性思考：

    • L2正则化真的让权重"接近零"吗？——不一定，它只是抑制增长，权重可以在整个训练过程中维持在较小值
    • 稀疏性真的更好吗？——Lottery Ticket Hypothesis的发现：稀疏网络（ pruning后）反而可能比dense网络表现更好

    2.6 特殊矩阵

    2.6.1 对称矩阵（Symmetric Matrix）

    
A = Aᵀ
    • 特征值为实数
    • 可正交对角化：A = QΛQᵀ
    • 深度学习应用：协方差矩阵、Gram矩阵、注意力机制中的对称性

    2.6.2 正交矩阵（Orthogonal Matrix）

    
AᵀA = AAᵀ = I
    • 保持向量长度：║Ax║₂ = ║x║₂
    • 保持内积：⟨Ax, Ay⟩ = ⟨x, y⟩
    • 应用：PCA中的基变换、QR分解、神经网络中的正交初始化

    2.6.3 深度学习的正交初始化问题

    "训练很深的网络时，权重矩阵的条件数（Condition Number）接近1很重要。"

    问题：标准随机初始化（如Xavier/He初始化）不能保证正交性。

    解决：深度学习中发展出专门的正交初始化方法，确保║W║₂的条件数接近1。

    2.7 行列式（Determinant）

    
det(A) = ∏ᵢ λᵢ   （特征值的乘积）

    性质：

    • det(A) = 0 ↔ 矩阵奇异（不可逆）
    • |det(A)| 表示体积缩放因子
    • 深度学习应用：雅可比矩阵的行列式用于变换的概率密度计算（变量变换公式）

    2.8 伪逆（Moore-Penrose Pseudoinverse）

    当 A 不是方阵或奇异时，传统逆不存在，但伪逆始终存在：

    
A⁺ = lim_{α→0} (AᵀA + αI)⁻¹Aᵀ

    计算特性：

    • 如果A列满秩（m≥n）：A⁺A ≈ I，解是最小二乘解中欧氏范数最小的
    • 如果A行满秩（n≥m）：AA⁺ ≈ I，解是最小范数解

    深度学习应用：

    • 线性回归的闭式解：x* = A⁺b
    • 训练循环神经网络时处理欠定系统

    2.9 矩阵的迹（Trace Operator）

    
Tr(A) = Σᵢ Aᵢᵢ = Σᵢ λᵢ

    有用性质：

    
Tr(ABC) = Tr(CAB) = Tr(BCA)  # 循环置换不变性
Tr(A) = Tr(Aᵀ)               # 转置不变性

    深度学习应用：

    • 循环置换不变性使我们可以自由地重新排列矩阵乘积的顺序，用于推导梯度公式
    • 方差 Var(y) = (1/n)Tr(Σ) 的计算

    2.10 特征分解（Eigendecomposition）

    定义

    A = QΛQ⁻¹，其中Q的列是特征向量，Λ是对角矩阵（特征值）。

    深度学习中的应用

    ① 主成分分析（PCA）——隐式使用特征分解：

    
# PCA的步骤（简化版）
X_centered = X - mean(X)
Cov = (1/n) X_centered.T @ X_centered  # 协方差矩阵
eigenvalues, eigenvectors = np.linalg.eigh(Cov)  # 特征分解

# 降维：只保留前k个最大的特征值对应的特征向量
top_k = eigenvectors[:, :k]
X_reduced = X_centered @ top_k

    ② 条件数分析：

    
κ(A) = |λ_max| / |λ_min|

    条件数大 → 矩阵病态（Ill-conditioned） → 求解线性系统时对扰动极敏感。

    批判性思考：

    深度网络为什么用SVD/特征分解不如用其他分解重要？
    答案：深度学习主要关心的是优化（而非线性系统求解），特征分解在大规模网络上计算代价极高（O(n³)）。取而代之的是随机化SVD、幂迭代等近似方法。

    2.11 奇异值分解（SVD）

    定义

    A = UΣVᵀ，其中：

    • U ∈ Rᵐˣᵐ：左奇异向量（AAᵀ的特征向量）
    • Σ ∈ Rᵐˣⁿ：对角矩阵，对角线元素为奇异值 σᵢ ≥ 0
    • V ∈ Rⁿˣⁿ：右奇异向量（AᵀA的特征向量）

    与特征分解的关系

    
A = UΣVᵀ  ←→  AᵀA = VΣᵀΣVᵀ  ←→  V的特征值 = σᵢ²

    深度学习应用

    应用原理
    降维截断SVD保留前k个最大奇异值
    去噪小奇异值对应噪声，丢弃
    矩阵补全推荐系统（协同过滤）
    伪逆计算A⁺ = VΣ⁺ᵀUᵀ，其中Σ⁺是对角线上取1/σᵢ（非零元素）

    批判性思考：

    SVD在深度学习中扮演"幕后英雄"角色——它不是深度学习模型的组成部分，但为许多理论分析（PCA、谱范数分析）和工程实践（去噪、压缩）提供了工具。

    2.12 行列式、迹与变量变换

    在概率密度变换中：

    
p_y(y) = p_x(g⁻¹(y)) · |det(∂g⁻¹/∂y)|
       = p_x(x) / |det(∂g/∂x)|

    其中雅可比矩阵（Jacobian）的行列式度量了体积变换因子。这是归一化流（Normalizing Flow）模型的数学基础之一。

    2.13 本章关键公式速查表

    公式用途

    Chapter 3: Probability and Information Theory（概率与信息论）

    3.1 本章核心论点

    "概率论是处理不确定性的数学框架。信息论使我们能够量化概率分布中的不确定性。"

    3.2 为什么要用概率论？

    计算机科学的确定性假设 vs 现实世界的随机性

    传统CS假设：

    • CPU精确执行指令
    • 程序行为完全可预测

    机器学习的现实：

    • 数据存在噪声（传感器误差、测量偏差）
    • 模型是对真实过程的简化（欠完全建模）
    • 许多问题本质上具有随机性（量子力学、博弈论）

    三种不确定性的来源

    来源描述例子
    内在随机性系统本身是随机的量子力学、理想洗牌后的扑克牌
    不完整可观测性确定系统但观测不到全部变量Monty Hall问题（参赛者视角）
    不完整建模丢弃了部分信息的模型导致不确定性机器人将连续空间离散化

    频率派 vs 贝叶斯派

    观点频率派概率贝叶斯概率
    解释事件的长期频率主观信念的量化
    先验信息不使用使用先验分布
    参数估计点估计后验分布
    适用场景可重复实验一次性事件（如医疗诊断）
    重要结论：只要常识推理对不确定性的要求一致地量化，贝叶斯概率和频率派概率的数学规则是完全等价的（Ramsey, 1926的证明）。

    3.3 随机变量与概率分布

    3.3.1 离散变量：概率质量函数（PMF）

    
# Bernoulli分布
# P(X=1) = φ, P(X=0) = 1-φ
P(X=x) = φˣ(1-φ)^(1-x)

# Multinoulli分布（分类分布）
# K个类别，参数p∈[0,1]^{K-1}
# 第K个类别概率 = 1 - 1ᵀp

    3.3.2 连续变量：概率密度函数（PDF）

    关键区别：

    PMFPDF
    概率P(X=x)是直接概率值p(x)是密度，非直接概率
    概率计算P(X=x)∫_S p(x)dx
    约束0 ≤ P ≤ 1p(x) ≥ 0（但不要求≤1）
    
# 均匀分布 U(a,b)
# p(x) = 1/(b-a)  for a ≤ x ≤ b
#        0         otherwise

    批判性思考：

    PDF的值可以大于1！这是否违反直觉？
    不违反——因为PDF的"概率"是通过积分定义的。在区间[a,b]上的总概率仍为1：
    ∫_{-∞}^{∞} p(x)dx = 1

    3.4 联合概率、边缘概率、条件概率

    核心公式速查

    
# 边缘概率（求和/积分法则）
P(x) = Σ_y P(x, y)           # 离散
p(x) = ∫ p(x, y) dy          # 连续

# 条件概率
P(y|x) = P(x, y) / P(x)      # 要求 P(x) > 0

# 链式法则（乘法法则）
P(x^(1), ..., x^(n))
  = P(x^(1)) Π_{i=2}^n P(x^(i) | x^(1), ..., x^(i-1))

    深度学习应用：链式法则直接对应自回归模型（Autoregressive Models）的概率分解。

    独立性与条件独立性

    
x ⊥ y          # x和y独立：P(x,y) = P(x)P(y)
x ⊥ y | z      # 给定z条件下独立：P(x,y|z) = P(x|z)P(y|z)

    3.5 期望、方差、协方差

    期望（Expectation）

    
E_{x~P}[f(x)] = Σ_x P(x)f(x)        # 离散
E_{x~p}[f(x)] = ∫ p(x)f(x)dx       # 连续

# 线性性质
E[αf(x) + βg(x)] = αE[f(x)] + βE[g(x)]

    方差（Variance）

    
Var(f(x)) = E[(f(x) - E[f(x)])²]
          = E[f(x)²] - E[f(x)]²

    协方差（Covariance）

    
Cov(f(x), g(y)) = E[(f(x) - E[f(x)])(g(y) - E[g(y)])]

    协方差矩阵：

    
Cov(x)_{i,j} = Cov(x_i, x_j)
对角线 = 各变量的方差

    批判性思考：

    协方差为零 ≠ 独立！这是经典误区。
    示例：设X~U(-1,1)，S以概率1/2为1否则为-1，令Y=SX。则：
    - Cov(X,Y) = 0
    - 但X和Y明显不独立（Y完全由X的符号决定）
    原因：协方差只衡量线性关系，不衡量非线性关系。

    3.6 常用概率分布

    3.6.1 高斯分布（正态分布）

    单变量：

    
N(x; μ, σ²) = (1/√(2πσ²)) exp(-(x-μ)²/(2σ²))

    多变量（多元正态）：

    
N(x; μ, Σ) = (1/((2π)^{n/2} det(Σ)^{1/2})) exp(-1/2 (x-μ)ᵀΣ^{-1}(x-μ))

    为什么高斯分布如此重要？

    原因解释
    中心极限定理大量独立随机变量的和近似正态分布
    最大熵原理在给定方差的所有分布中，正态分布的信息熵最大（最"不偏"）
    数学性质好线性变换后仍是正态分布；边缘/条件分布也是正态分布

    深度学习中的高斯分布：

    -权重初始化（均值0，方差合适）

    • 变分推断中的后验近似
    • GAN的噪声输入
    • 强化学习中的不确定性建模

    3.6.2 指数分布与Laplace分布

    指数分布（在x=0处有尖峰）：

    
p(x; λ) = λ 1_{x≥0} exp(-λx)

    Laplace分布（可在任意点μ放置尖峰）：

    
Laplace(x; μ, γ) = (1/2γ) exp(-|x-μ|/γ)

    3.6.3 经验分布（Empirical Distribution）

    
p̂(x) = (1/m) Σ_{i=1}^m δ(x - x^(i))
    经验分布将概率质量1/m放在每个训练样本上。从频率派角度，这是"最合理"的分布估计；从贝叶斯角度，它是数据的似然函数基础。

    3.6.4 混合分布

    
P(x) = Σ_i P(c=i) P(x|c=i)

    高斯混合模型（GMM）：

    • 每个组件是高斯分布
    • 可以逼近任意光滑密度（通用逼近器）
    • 深度学习应用：GMM用于语音识别、密度估计、聚类

    潜在变量（Latent Variable）：

    c是潜在变量（不可直接观测）。引入潜在变量使得模型能够表示更复杂的分布，同时提供了可解释性（如GMM中c代表"类别"）。

    3.7 常用函数

    Sigmoid函数

    
σ(x) = 1 / (1 + exp(-x))

    性质：

    
σ'(x) = σ(x)(1 - σ(x))     # 导数形式优雅！
1 - σ(x) = σ(-x)           # 对称性
log σ(x) = -ζ(-x)          # 与softplus的关系

    深度学习应用：

    • 二分类输出层（伯努利分布的参数φ）
    • 门控机制（LSTM中的遗忘门、输入门）
    • Bernoulli分布的规范参数化

    问题：当x很大或很小时，σ(x)趋于饱和（梯度接近0）→ 梯度消失问题。

    Softplus函数

    
ζ(x) = log(1 + exp(x))

    性质：

    
ζ'(x) = σ(x)
ζ(x) - ζ(-x) = x

    深度学习应用：生成正参数（β, σ²）时替代exp()，数值更稳定。

    批判性思考：

    ReLU = max(0, x) 的"softplus版本"就是softplus。那为什么不直接用ReLU？
    - ReLU计算快（简单阈值）
    - 但softplus处处可微（生物合理性？）
    - 现代深度学习框架主要用ReLU，因为其稀疏激活和梯度不消失的特性

    3.8 贝叶斯法则（Bayes' Rule）

    
P(x|y) = P(x)P(y|x) / P(y)

    其中 P(y) = Σ_x P(y|x)P(x)（全概率公式）

    应用场景：

    
# 医疗诊断
# P(疾病|症状) = P(症状|疾病)P(疾病) / P(症状)

# 机器学习中的推断
# P(模型参数|数据) = P(数据|参数)P(参数) / P(数据)

    3.9 连续变量的技术细节

    变量变换公式

    
# 标量情况
p_y(y) = p_x(g^{-1}(y)) · |dx/dy|
       = p_x(g^{-1}(y)) / |g'(g^{-1}(y))|

# 向量情况
p_x(x) = p_y(g(x)) · |det(∂g/∂x)|

    常见错误：

    
# ❌ 错误做法
p_y(y) = p_x(√y)  # 假设 y = x²

# ✓ 正确做法（需考虑雅可比行列式）
p_y(y) = p_x(√y) · (1/(2√y)) + p_x(-√y) · (1/(2√y))

    3.10 信息论基础

    3.10.1 自信息（Self-Information）

    
I(x) = -log P(x)

    直观理解：

    • P(x)大 → I(x)小（常发生的事情，信息量低）
    • P(x)小 → I(x)大（罕见事件，信息量高）
    • 独立事件的信息可加：I(x,y) = I(x) + I(y) iff x⊥y

    3.10.2 香农熵（Shannon Entropy）

    
H(X) = E_{x~P}[I(x)] = -E_{x~P}[log P(x)]
     = -Σ_x P(x)log P(x)

    物理含义：编码P分布的符号所需的最少比特数（使用最优编码时）。

    二值变量的熵：

    
H(p) = -plog(p) - (1-p)log(1-p)

    当p=0.5时熵最大（最不确定）；当p→0或p→1时熵→0（几乎确定）。

    3.10.3 KL散度（Kullback-Leibler Divergence）

    
D_KL(P || Q) = E_{x~P}[log(P(x)/Q(x))]
             = Σ_x P(x)log P(x) - Σ_x P(x)log Q(x)

    核心性质：

    • 非负性：D_KL(P||Q) ≥ 0（当且仅当P=Q时等于0）
    • 非对称性：D_KL(P||Q) ≠ D_KL(Q||P)
    • 链式法则：可用于分解联合分布

    批判性思考——KL不对称的实践意义：

    方向效果
    D_KL(P\\Q)在P高概率处让Q也高概率（覆盖所有模式，模糊边缘）
    D_KL(Q\\P)在P低概率处让Q也低概率（选择一个模式，忽略其他）

    这就是VAE（变分自编码器）和GAN（生成对抗网络）的核心权衡：

    • VAE：最小化D_KL(q(z|x) || p(z|x))，倾向于模糊的分布（多模式平均）
    • GAN：隐式最小化某种散度，但生成锐利的样本

    3.10.4 交叉熵（Cross-Entropy）

    
H(P, Q) = H(P) + D_KL(P || Q)
        = -E_{x~P}[log Q(x)]

    实际应用：由于H(P)是常数，最小化交叉熵等价于最小化KL散度。

    3.11 结构化概率模型（Structured Probabilistic Models）

    问题

    深度学习需要处理大量随机变量的联合分布（如词向量、像素、隐藏单元）。

    直接存储P(x₁,x₂,...,xₙ)：

    • 需要指数级参数（2ⁿ种可能）
    • 不可行！

    解决思路：因式分解

    关键洞察：许多变量只与少数其他变量直接相关（条件独立性）。

    
# 例子：a影响b，b影响c，但a和c在给定b时独立
P(a,b,c) = P(a) P(b|a) P(c|b)

    图模型分类

    类型边类型代表模型
    有向图模型（贝叶斯网络）有向边（条件独立）朴素贝叶斯、LDA、VAE
    无向图模型（马尔可夫网络）无向边（团势函数）CRF、玻尔兹曼机

    批判性思考：

    图模型是深度学习的重要组成部分，但不是所有深度学习都基于图模型。
    现代深度学习更倾向于隐式定义分布（如GAN通过博弈论定义，NF通过可逆变换定义），而不是显式图结构。
    但图模型提供了可解释性和理论分析的重要框架。

    Chapter 4: Numerical Computation（数值计算）

    4.1 本章核心目标

    深度学习本质上是大规模数值优化。理解数值计算的基本问题是理解训练过程（梯度消失、爆炸、收敛速度）的数学基础。

    4.2 溢出（Overflow）与下溢（Underflow）

    问题的根源

    数字计算机用有限位模式表示无限多的实数——这意味着近似误差是不可避免的。

    下溢（Underflow）

    定义：接近零的数被四舍五入为0。

    危害：

    
# softmax的数值不稳定
# 当所有 x_i 都等于很大的负数c时
exp(c) → 0（机器下溢）
# 分母变成0 → 结果未定义
# log(0) → -∞ → NaN传播

    上溢（Overflow）

    定义：超大数被近似为∞或-∞。

    危害：

    
# 当 x_i 都等于很大的正数c时
exp(c) → ∞ → NaN

    Softmax的数值稳定化

    
# 标准softmax（不稳定）
def softmax_unstable(x):
    exp_x = np.exp(x)
    return exp_x / np.sum(exp_x)

# 稳定化版本（减去最大值）
def softmax_stable(x):
    # 减去max(x_i)，最大指数变成exp(0)=1，不会溢出
    # 至少有一个分母项=1，不会下溢出零
    e_x = np.exp(x - np.max(x))
    return e_x / np.sum(e_x)

# log-softmax（避免log(0)）
def log_softmax_stable(x):
    return x - np.log(np.sum(np.exp(x - np.max(x))))

    工程实践：现代框架（PyTorch、TensorFlow）的softmax默认已稳定化。

    批判性思考：

    为什么深度学习框架不自动处理所有数值稳定性问题？
    因为并非所有不稳定情况都能自动检测——某些"边界行为"本身就是算法想要的特性（如某些正则化效果）。自动化处理可能导致意外改变算法行为。

    4.3 病态条件（Poor Conditioning）

    条件数（Condition Number）

    
κ(A) = max_{i,j} |λ_i / λ_j|  = |λ_max / λ_min|

    含义：输入的相对误差在输出中最多被放大 κ(A) 倍。

    深度学习中的应用：

    
# 当A是Hessian矩阵时
# 条件数大 = 曲率在不同方向差异大
# → 梯度下降困难（某些方向陡峭，某些方向平缓）
# → 不得不使用很小的学习率来避免overshooting

    优化视角的困难：

    
条件数大 = "峡谷地形"
- 梯度下降在"峭壁"上来回弹跳
- 即使达到最优步长，在平坦方向进展极慢

    4.4 基于梯度的优化

    4.4.1 基本框架

    
优化 = 最小化（或最大化）函数 f(x)
目标：找到 x* = arg min f(x)
    名称含义
    目标函数（Objective）要最小化的函数
    代价函数（Cost/Loss/Error）目标函数的别名
    梯度下降（Gradient Descent）沿负梯度方向搜索

    术语表：

    4.4.2 梯度下降的直觉

    一维情况：

    
f'(x) = dy/dx  →  斜率
f(x + ε) ≈ f(x) + εf'(x)

    关键洞察：如果f'(x) < 0，沿正方向移动会降低f(x)。

    多维推广（最速下降法/Steepest Descent）：

    
# 方向 u（单位向量）上的方向导数
D = uᵀ∇_x f(x)

# 最速下降方向（与梯度相反）
x' = x - ε∇_x f(x)  # ε是学习率

    4.4.3 学习率（Learning Rate）的选择

    方法描述
    固定学习率简单，但可能震荡
    线搜索（Line Search）在每步找最优步长 ε* = arg min_ε f(x - ε∇f(x))
    衰减学习率随训练进度降低

    4.5 临界点分析（Critical Points）

    临界点类型

    
f'(x) = 0 的点称为临界点（或驻点）：
    类型一维条件多维条件（基于Hessian）
    局部最小值f''(x) > 0H正定（所有λ>0）
    局部最大值f''(x) < 0H负定（所有λ<0）
    鞍点（Saddle）f''(x) = 0H同时有正负特征值

    深度学习中的鞍点问题：

    早期观点认为：深度网络的损失面充满局部最小值，使优化困难。
    现代观点（SAGAN等研究）：高维空间中的局部最小值极少——大多数临界点是鞍点。真正的问题是：
    1. 鞍点附近的收敛速度慢
    2. 高度退化的Hessian（大量零特征值）导致" plateau"（高原）

    4.6 梯度估计：雅可比矩阵与Hessian矩阵

    4.6.1 雅可比矩阵（Jacobian）

    
# f: R^m → R^n 的导数
J_{i,j} = ∂f_i / ∂x_j
# 形状：n × m

    应用：向量值函数对向量的导数（如RNN的隐藏状态展开）。

    4.6.2 Hessian矩阵

    
# f: R^n → R 的二阶导数
H_{i,j} = ∂²f / (∂x_i ∂x_j)
# 对称矩阵（连续偏导可交换时）
# 形状：n × n

    性质：

    • Hessian = 梯度∇f的Jacobian
    • 特征值决定曲率
    • 条件数 = |λ_max| / |λ_min|

    4.6.3 二阶泰勒展开

    
f(x) ≈ f(x⁰) + (x-x⁰)ᵀg + 1/2 (x-x⁰)ᵀH(x-x⁰)

    梯度步长分析：

    
f(x⁰ - εg) ≈ f(x⁰) - εgᵀg + 1/2 ε²gᵀHg

最优步长（近似）：
ε* = (gᵀg) / (gᵀHg)

最坏情况（g沿最大特征值方向）：
ε* ≈ 1/λ_max

    4.7 牛顿法（Newton's Method）

    二阶优化的典型代表

    
# 泰勒展开到二阶
f(x) ≈ f(x⁰) + (x-x⁰)ᵀ∇f(x⁰) + 1/2 (x-x⁰)ᵀHf(x⁰)(x-x⁰)

# 对x求导并设为0
∇f(x⁰) + Hf(x⁰)(x-x⁰) = 0

# 解析解
x* = x⁰ - Hf(x⁰)⁻¹∇f(x⁰)

    优点：对于正定二次函数，一步到达最优！

    缺点：

    • 需要计算Hessian（H ∈ R^{n×n}，n可能是 billions）
    • Hessian可能不可逆（奇异或接近奇异）
    • 不适用于鞍点（牛顿法被吸引到鞍点）

    深度学习中的困境：

    
# 深度网络的Hessian
# 维度：数十亿 × 数十亿
# 无法直接存储，更无法求逆

# 解决方案：
# 1. 拟牛顿法（Quasi-Newton）：L-BFGS（内存受限）
# 2. 自然梯度（Natural Gradient）：用Fisher信息矩阵替代H
# 3. 近似方法：K-FAC（Hessian-free优化）

    4.8 优化算法的分类

    类型阶数代表算法特点
    零阶不需要导数随机搜索、贝叶斯优化样本效率低
    一阶只需要梯度SGD、Momentum、Adam深度学习主力
    二阶需要Hessian牛顿法、拟牛顿法理论上更快，但计算代价高

    4.9 约束优化与KKT条件

    4.9.1 拉格朗日函数

    
# 约束：min f(x)
#   subject to g_i(x) = 0 (等式约束)
#             h_j(x) ≤ 0  (不等式约束)

# 广义拉格朗日
L(x, λ, α) = f(x) + Σ_i λ_i g_i(x) + Σ_j α_j h_j(x)
# 其中 α_j ≥ 0（KKT乘子）

    4.9.2 KKT条件（Karush-Kuhn-Tucker）

    KKT条件是约束优化问题最优解的必要条件（非充分）：

    
# 1. 平稳性：∇_x L = 0
# 2. 原始可行性：g_i(x) = 0, h_j(x) ≤ 0
# 3. 对偶可行性：α_j ≥ 0
# 4. 互补松弛：α_j · h_j(x*) = 0

    深度学习中的约束优化：

    • 权重范数约束（如 ||W|| ≤ 1）
    • 批归一化（BatchNorm）的运行时均值/方差约束
    • 生成模型中的隐变量约束

    4.10 线性最小二乘示例

    无约束情况

    
# min f(x) = 1/2 ||Ax - b||²
# ∇_x f(x) = Aᵀ(Ax - b) = 0
# x* = (AᵀA)⁻¹Aᵀb = A⁺b（伪逆解）

    带约束情况（||x||² ≤ 1）

    
# min 1/2||Ax-b||²
# subject to xᵀx ≤ 1

# 解的形式：x* = (AᵀA + 2λI)⁻¹Aᵀb
# 其中 λ ≥ 0 是拉格朗日乘子
# 通过梯度上升调整λ直到满足约束

    5.5 学习范式：监督 vs 无监督 vs 半监督

    5.5.1 无监督学习（Unsupervised Learning）

    
# 经验：数据集中的特征 x

# - 表示学习（Autoencoder）
# - 生成模型（GAN、VAE）

    5.5.2 监督学习（Supervised Learning）

    
# 经验：(x, y) 对，其中 y 是标签/目标
# 目标：学习 p(y|x) 或确定性映射 f(x)

# 链式法则连接监督与无监督：

    5.6 线性回归示例：端到端学习系统

    5.6.1 模型定义

    
# 输入：x ∈ R^n
# 输出：ŷ = wᵀx + b
# 参数：w ∈ R^n, b ∈ R

    5.6.2 代价函数选择

    均方误差（MSE）：

    
J(w, b) = (1/2m) Σ_i (ŷ^(i) - y^(i))²
        = (1/2m) ||Xw + b1 - y||²

    为什么用平方？

    • 连续可微
    • 数学上处理加性高斯噪声时自然出现（最大似然估计）
    • 对大误差惩罚更重（平方增长）

    5.6.3 正规方程（闭式解）

    
# X ∈ R^{m×n}, y ∈ R^m
# ŵ = (XᵀX)^{-1}Xᵀy    （假设X列满秩）

    问题：XᵀX 可能奇异（不可逆）！

    解决：添加正则化项

    
# Ridge回归
ŵ = (XᵀX + λI)^{-1}Xᵀy

    5.7 过拟合、欠拟合与容量

    5.7.1 核心矛盾

    
欠拟合（Underfitting）：
  模型太简单，无法捕捉数据中的规律
  → 训练误差高、测试误差高

过拟合（Overfitting）：
  模型太复杂，记住训练数据的噪声
  → 训练误差低、测试误差高（gap大）

    5.7.2 容量（Capacity）的概念

    容量 = 模型拟合各种函数的能力

    容量过低容量过高
    线性模型对非线性问题高次多项式对简单规律
    欠拟合过拟合

    5.7.3 偏差-方差分解（Bias-Variance Decomposition）

    
# 期望预测误差（对测试点x₀）
E[(y - ŷ)²] = Bias² + Variance + Irreducible Noise

# Bias = (E[ŷ] - y)²   （模型本身的系统性误差）
# Variance = E[(ŷ - E[ŵ])²]   （模型对数据的敏感度）
# Noise = σ²   （数据本身的噪声，不可消除）

    直观理解：

    现象原因解决
    高偏差模型太简单（容量低）增加模型复杂度
    高方差模型太复杂（容量高）更多数据 / 正则化

    深度学习的特殊现象：

    现代深度学习发现：超参数化（overparameterized）模型（如数十亿参数的神经网络）可以在训练数据上完美拟合，同时在测试数据上仍有良好泛化——这与传统的"容量-泛化"理论相矛盾。
    这推动了过度参数化理论和双下降（Double Descent）现象的研究。

    5.8 交叉验证（Cross-Validation）

    K折交叉验证

    
def k_fold_cv(model, X, y, k=5):
    """
    将数据分成k份
    轮流用k-1份训练，1份测试
    返回k个性能估计的平均值
    """
    scores = []
    indices = np.random.permutation(len(X))
    fold_size = len(X) // k
    
    for i in range(k):
        val_idx = indices[ifold_size:(i+1)fold_size]
        train_idx = np.concatenate([indices[:i*fold_size], 
                                    indices[(i+1)*fold_size:]])
        
        model.fit(X[train_idx], y[train_idx])
        scores.append(model.score(X[val_idx], y[val_idx]))
    
    return np.mean(scores), np.std(scores)

    深度学习中的交叉验证：

    • 大规模数据时代：通常不需要（数据集足够大）
    • 小数据场景：仍然关键（医疗、稀有事件建模）
    • 替代方法：留出验证集（Hold-out validation）

    5.11 传统机器学习的泛化障碍

    这是理解为什么需要深度学习的关键！

    5.11.1 维数灾难（Curse of Dimensionality）

    当数据的维度增加时，体积呈指数增长，导致可用的数据点变得稀疏。
    
# d维超立方体中单位球的比例
# 随着d增加，这个比例趋近于0！
# → 在高维空间中，大多数区域是"空"的

# 例子：100维空间
# - 边长0.01的超立方体占据总体积的 (0.01)^100 ≈ 0
# → 即使有10亿个样本，在100维空间中也是杯水车薪

    影响：

    • 需要指数级多的数据来覆盖高维空间
    • 最近邻等方法在高维退化为随机猜测
    • 传统机器学习在高维（如图像、语音）上失败

    5.11.2 流形假设（Manifold Assumption）

    真实世界的高维数据主要分布在低维流形附近。
    
# 例：
# - 图像空间是 784 维，但"有意义的图像"分布在远小于784维的流形上
# - 人脸图像：所有像素在光照/姿态/表情变化下形成低维流形

# 关键洞察：
# → 学习算法不需要在整的高维空间泛化
# → 只需要在数据流形附近泛化
# → 这就是为什么深度学习中的"表示学习"如此有效

    5.11.3 局部泛化（Local Generalization）

    传统机器学习主要依赖"局部平滑性"——相似输入产生相似输出。

    问题：许多任务需要非局部泛化。

    
# 例：
# - 识别"有耳朵的哺乳动物"
# → 机器需要识别全新组合（河马从未在训练集中出现过）
# → 这需要从已知的概念（"耳朵"、"哺乳动物"）进行组合推理
# → 这正是深度层次化表示的优势

# 对比：
# - 传统ML：记住训练集中的模式，在局部邻域平滑
# - 深度学习：通过层次化概念，实现跨区域的组合泛化

    Q1：深度学习真的需要那么多数学吗？

    答案：基础数学足以理解大多数实践，但深入研究（如优化理论、统计学习理论）需要更高级的数学。

    层次所需数学
    使用框架线性代数直觉 + 概率基础
    调参与改进本书Part I全部内容
    理论分析凸优化、矩阵分析、高维统计
    前沿研究随机矩阵理论、谱图理论、微分几何

    Q2：为什么概率论在深度学习中如此核心？

    从三个视角理解：

  • 建模视角：神经网络是概率分布的参数化
  • 推断视角：学习 = 后验推断（贝叶斯观点）
  • 信息论视角：损失函数 = 某种信息度量（交叉熵、互信息）

    • Q3：凸优化 vs 非凸优化——深度学习为何选择hard模式？

    凸优化的优势：

    • 所有局部最优 = 全局最优
    • 丰富理论支撑
    • 收敛性有保证

    深度学习为什么是非凸的：

    • 非线性激活函数 → 非凸损失面
    • 过参数化 → 参数数量 >> 数据点数
    • 大量局部最优/鞍点

    但实践中SGD+动量仍能工作：

    • 高维空间鞍点比局部最小值更普遍（Dauphin et al.）
    • SGD的噪声有助于逃离浅局部最小值
    • 超参数化模型的损失面在高维空间意外地"友善"

    Q4：表示学习 vs 传统特征工程的本质区别是什么？

    
传统特征工程：
  特征设计 → 特征 → 学习器 → 输出
  （人工）  （固定） （学习）

表示学习：
  原始数据 → 多层学习特征 → 输出
            （端到端共同优化）

    关键区别：

  • 特征来源：人工设计 vs 自动学习
  • 优化目标：学习器单独优化 vs 端到端联合优化
  • 迁移能力：固定特征 vs 可迁移的层次化表示

    • 深度学习与芙宁娜的联想

    芙宁娜在五百年的舞台生涯中学会了扮演任何角色——这何尝不是一种"表示学习"？
    她学会了在不同场景下提取"关键特征"（观众的表情、语调的变化、舞台的气氛），然后组合这些低层表示为高层表演——就像深度网络从像素到边缘到物体部件到完整物体的层次化表示一样。

    深度前馈网络

    "深度前馈网络是深度学习模型的典型代表，其目标是近似某个函数 f，通过学习参数 θ 得到最佳函数逼近。"*

    6.1 核心概念

    什么是前馈神经网络？

    特征描述
    别名多层感知机 (MLP), 深度前馈网络
    目标近似函数 f*(x)，学习映射 y = f(x; θ)
    结构输入层 → 隐藏层 → 输出层（无反馈连接）
    核心思想通过组合多个非线性函数来学习表示

    前馈 vs 线性模型的对比

    线性模型的局限性：

    • 无法表示非线性关系
    • 只能学习 f(x) = w^T x + b

    解决方案：引入非线性变换

    
y = f(x; θ, w) = φ(x; θ)^T w

    其中 φ 是学习到的非线性特征表示，而非人工设计。

    6.2 学习XOR：经典案例

    问题描述

    XOR函数无法被线性模型正确分类：

    x₁x₂XOR
    000
    011
    101
    110

    解决方案：双层神经网络

    
f(x; W, c, w, b) = w^T · max(0, W^T x + c) + b

    关键洞察：

    • 单层网络无法解决XOR问题
    • 两层网络（一个隐藏层）可以解决
    • 隐藏单元使用ReLU激活函数

    6.3 基于梯度的学习

    代价函数设计原则

  • 代价函数必须有大的、可预测的梯度
  • 交叉熵损失优于MSE

    • - 原因：交叉熵包含log操作，可以抵消softmax的exp操作

    - 避免梯度消失问题

    输出单元类型

    输出类型激活函数适用场景
    线性输出无（identity）高斯分布输出
    Sigmoid输出σ(z)Bernoulli分布（双分类）
    Softmax输出softmax(z)多分类问题
    混合输出多输出Sigmoid多标签分类

    Softmax函数详解

    
\text{softmax}(z)_i = \frac{\exp(z_i)}{\sum_j \exp(z_j)}

    数值稳定性技巧：

    
\text{softmax}(z) = \text{softmax}(z - \max_i z_i)

    减去最大值避免数值溢出。

    6.4 隐藏单元设计

    ReLU (Rectified Linear Unit)

    
f(x) = \max(0, x)

    优点：

    • 计算简单高效
    • 梯度不会饱和（对正数）
    • 稀疏激活特性

    问题： Dying ReLU

    • 当 x < 0 时，梯度为0
    • 导致"死神经元"问题

    ReLU的变体

    变体公式特点
    Leaky ReLUf(x) = max(αx, x), α≈0.01允许小的负梯度
    PReLUf(x) = max(αx, x)，α可学习自适应参数
    ELUf(x) = x if x>0, α(e^x-1) if x≤0接近零均值
    Maxoutmax(w₁^T x + b₁, w₂^T x + b₂)学习激活形状

    激活函数选择原则

    默认推荐：ReLU
    - 收敛快
    - 计算效率高
    - 调参简单

    注意事项：

    • Sigmoid：已过时，主要用于输出层
    • Tanh：有时用于RNN，但在隐藏层表现不佳
    • 永远不要在隐藏层使用线性激活函数（除非输出层）

    6.5 架构设计

    万能近似定理 (Universal Approximation Theorem)

    定理内容：

    • 单个隐藏层的神经网络可以近似任何连续函数（在一定条件下）
    • 但实际应用中存在严重局限：

    - 隐藏层可能需要极大

    - 训练算法可能无法找到正确的参数

    - 容易过拟合

    架构设计原则

  • 网络深度：深度网络比浅层网络更高效

    • - 指数级减少表示某些函数所需的隐藏单元数量

  • 层宽 vs 层深：

    • - 更深的网络可以用更少的参数表示复杂函数

    - 但过深会导致优化困难（梯度问题）

  • 跳层连接 (Skip Connections)：

    • - 帮助梯度流动

    - ResNet的核心思想

    6.6 反向传播算法

    核心思想

    通过计算图表示复杂函数，使用链式法则求导。

    算法步骤

    
对于每个样本：
1. 前向传播：计算所有中间激活值
2. 反向传播：计算每个参数的梯度
3. 更新参数：θ = θ - α∇θJ(θ)

    y = W3 @ h2 + b3
    return y

def backward(x, y, params, gradients):
    # 从输出层反向计算梯度

    grad_W3 = grad_y @ h2.T
    grad_h2 = W3.T @ grad_y
    grad_h2_raw = grad_h2 * (h2 > 0)  # ReLU导数

    对于层 l：

    
\frac{\partial J}{\partial W^{(l)}} = \frac{\partial J}{\partial a^{(l)}} \cdot \frac{\partial a^{(l)}}{\partial W^{(l)}}

    Chapter 7: Regularization for Deep Learning

    深度学习正则化

    "正则化是任何旨在减少泛化误差（而非训练误差）的学习算法修改。"

    7.1 正则化的核心哲学

    偏差-方差分解

    
\text{MSE} = \text{Bias}^2 + \text{Variance} + \text{Irreducible Error}

    正则化的本质：用增加偏差换取减少方差。

    正则化策略分类

    
正则化方法
├── 参数范数惩罚 (L1, L2)
├── 数据增强
├── 噪声注入
├── 早停法 (Early Stopping)
├── Dropout
├── 集成方法 (Bagging)
├── 半监督学习
└── 对抗训练

    7.2 参数范数惩罚

    L2正则化（权重衰减）

    
\tilde{J}(w; X, y) = J(w; X, y) + \frac{\alpha}{2}w^T w

    梯度：

    
\nabla_w \tilde{J} = \alpha w + \nabla_w J

    更新规则：

    
w \leftarrow (1 - \alpha \eta)w - \eta \nabla_w J

    效果：

    • 将权重收缩到原点附近
    • 沿着Hessian矩阵特征值衰减：有效参数减少

    L1正则化

    
\Omega(\theta) = \|w\|_1 = \sum_i |w_i|

    总目标：

    
\tilde{J}(w; X, y) = J(w; X, y) + \alpha \|w\|_1

    特点：

    • 产生稀疏权重
    • 等价于拉普拉斯先验的MAP估计
    • 自动进行特征选择

    L1 vs L2正则化对比

    特性L1L2
    解的形状稀疏平滑
    计算需要次梯度闭式解
    特征选择有无
    渐变行为固定步长衰减渐进衰减

    弹性网 (Elastic Net)

    
\Omega(\theta) = \lambda \|w\|_1 + (1-\lambda)\|w\|_2^2

    结合L1和L2的优点。

    核心思想

    "训练模型所需的泛化误差最小化的最佳方式，是使用无限多的真实数据。"
    — 数据增强的本质是人工合成更多训练数据

    图像数据增强

    方法描述效果
    随机裁剪Random Crop提高位置不变性
    水平翻转Horizontal Flip简单有效
    色彩抖动Color Jitter提高颜色鲁棒性
    随机旋转Rotation方向不变性
    弹性变形Elastic Deformation形变鲁棒性
    噪声注入Noise Addition抗噪声

    对抗样本增强

    通过在训练时加入对抗样本，提高模型鲁棒性。

    7.4 噪声鲁棒性

    输入噪声

    在输入层添加噪声：

    
\hat{x} = x + \epsilon, \quad \epsilon \sim \mathcal{N}(0, \sigma^2)

    隐藏层噪声 (Dropout)

    Dropout可以看作：

    • 集成学习（Bagging）的近似
    • 一种隐式的正则化

    Dropout算法：

    
for each training example:
    for each layer:
        create mask vector m
        h_masked = h * m  # element-wise multiplication
        # typically p=0.5 for hidden layers

    Dropout的解释

  • 集成解释：每次训练时创建不同的子网络，最后集成
  • 正则化解释：添加噪声防止过拟合
  • 稀疏激活：类似生物神经网络的稀疏性

    算法流程

    
train:

    7.7 Bagging与集成方法

    Bagging (Bootstrap Aggregating)

    
\hat{y}_{\text{ensemble}} = \frac{1}{k} \sum_{i=1}^{k} \hat{y}_i

    深度学习中的集成

    • 模型平均：训练多个模型，取预测平均
    • 快照集成：在训练过程中保存多个检查点
    • 多尺度方法：不同输入尺度的预测融合

    7.8 对抗训练

    对抗样本

    
x' = x + \epsilon \cdot \text{sign}(\nabla_x J(\theta, x, y))

    关键洞察：

    • 对抗样本在原始样本附近
    • 但模型对其预测错误
    • 表明模型在局部线性而非真正理解

    对抗训练正则化

    
\tilde{J} = \alpha J(x, y) + (1-\alpha)J(x', y)

    7.9 批判性思考

    正则化方法的权衡

    方法优点缺点
    L2通用、计算简单不产生稀疏解

    Dropout强大、无需调参训练时间增加
    早停简单需要验证集
    数据增强最有效需要领域知识

    正则化的本质

    正则化不是免费的午餐。最好的正则化策略是使用更多真实数据。

    组合策略

    实践中常组合多种正则化方法：

    Chapter 8: Optimization for Training Deep Models

    深度模型训练优化

    "训练深度神经网络本质上是一个高度非凸的优化问题。"

    8.1 优化与深度学习的关系

    优化 vs 泛化

    机器学习优化目标：

    
\min_{\theta} \frac{1}{m} \sum_{i=1}^{m} L(f(x^{(i)}; \theta), y^{(i)})

    真正的目标：最小化泛化误差，而非训练误差。

    深度学习优化的挑战

  • 病态条件数

    • - Hessian矩阵条件数差

    - 梯度在某些方向变化快，某些方向变化慢

  • 局部极小值

    • - 高维空间的局部极小值问题

    - 鞍点问题

  • 悬崖与梯度爆炸

    • - RNN中尤为突出

    - 梯度裁剪是常见解决方案

  • 长期依赖

    • - 梯度消失/爆炸

    - LSTM/GRU的核心动机

    8.2 随机梯度下降 (SGD)

    经典SGD

    
while True:
    samples = sample_training_data(data, batch_size)
    gradients = compute_gradients(loss, samples)
    theta = theta - learning_rate * gradients

    收敛性分析

    对于凸函数：

    
\mathbb{E}[J(\theta_T)] - J(\theta^) \leq \frac{\|\theta_0 - \theta^\|^2}{2\eta T} + \frac{\eta G}{2}

    其中 G 是梯度的方差上界。

    学习率调度

    策略公式特点
    恒定学习率η(t) = η简单但不稳定
    阶梯衰减η(t) = η₀ / (1 + t/decay)常用
    指数衰减η(t) = η₀ * exp(-t/decay)快速衰减
    余弦退火η(t) = η_min + (η_max - η_min) * (1+cos(...))/2SGDR使用

    8.3 动量法 (Momentum)

    物理类比

    动量法类似于一个有质量的物体在损失曲面上滚动。

    算法

    
v = beta  v + (1 - beta)  gradients  # 速度累积
theta = theta - learning_rate * v

    常用参数：β = 0.9

    Nesterov动量

    
v = beta  v + (1 - beta)  gradients(theta - beta * v)  # 预计算梯度
theta = theta - learning_rate * v

    效果：比标准动量更快收敛。

    8.4 自适应学习率方法

    AdaGrad

    
grad_squared = grad_squared + gradients  2
theta = theta - learning_rate * gradients / (sqrt(grad_squared) + epsilon)

    优点：自动调整学习率，适合稀疏数据

    缺点：学习率持续下降，可能过早停止

    RMSProp

    
grad_squared = beta  grad_squared + (1 - beta)  gradients  2
theta = theta - learning_rate * gradients / (sqrt(grad_squared) + epsilon)

    Adam (Adaptive Moment Estimation)

    
m = beta1  m + (1 - beta1)  gradients      # 一阶矩估计
v = beta2  v + (1 - beta2)  gradients  2  # 二阶矩估计
m_hat = m / (1 - beta1  t)                  # 偏差修正
v_hat = v / (1 - beta2  t)
theta = theta - learning_rate * m_hat / (sqrt(v_hat) + epsilon)

    默认参数：β₁ = 0.9, β₂ = 0.999, ε = 10⁻⁸

    各方法对比

    方法优点缺点
    SGD + Momentum通用、稳定需要调学习率
    AdaGrad稀疏数据友好后期学习率衰减
    RMSProp非凸问题稳定需要调超参
    Adam默认最优可能不收敛

    8.5 二阶方法

    牛顿法

    
theta = theta - H^(-1) * gradients  # H是Hessian矩阵

    问题：

    • 计算Hessian矩阵 O(n²)
    • 矩阵求逆 O(n³)
    • 对于深度学习不实用

    拟牛顿法

    • L-BFGS：有限内存近似
    • 对大规模问题仍不实用

    K-FAC (Kronecker-Factored Approximate Curvature)

    • 用于深度学习的二阶近似
    • 近似Hessian的Kronecker分解

    8.6 梯度裁剪

    梯度爆炸问题

    
gradients = gradients / max(norm(gradients) / clip_norm, 1)

    RNN中的应用

    梯度裁剪是训练RNN的核心技术之一，使训练更加稳定。

    8.7 批量归一化 (Batch Normalization)

    核心思想

    
\hat{x}^{(k)} = \frac{x^{(k)} - \mu^{(k)}}{\sqrt{\sigma^{(k)²} + \epsilon}}
y^{(k)} = \gamma^{(k)} \hat{x}^{(k)} + \beta^{(k)}

    作用

  • 内部协变量转移减轻

    • - 稳定每层输入分布

    - 允许更高的学习率

  • 正则化效果

    • - 每个batch的均值/方差有噪声

    - 轻微的正则化

  • 允许使用饱和激活函数

    • - 如Sigmoid、Tanh

    - 因为归一化后不易饱和

    在网络中的位置

    
Layer -> BatchNorm -> Activation -> Layer

    实用建议

    默认选择：Adam + 适当的初始学习率（3e-4）
    稳定收敛：SGD + Momentum
    最终性能：SGD通常优于Adam，但需要更多调参

    局部最小值问题

    重要发现：

    • 高维空间的局部极小值很少
    • 鞍点才是主要问题
    • 随机梯度足以逃离鞍点

    "深度学习的核心问题是优化，而非过拟合。"

    • 损失表面的几何性质值得研究

    Chapter 9: Convolutional Networks

    卷积神经网络

    "卷积网络是专门用于处理具有网格状拓扑结构数据的神经网络。"

    9.1 卷积操作

    一维卷积

    
s(t) = (x * w)(t) = \int x(a)w(t-a)da

    二维卷积（图像）

    
S(i,j) = (I * K)(i,j) = \sum_m \sum_n I(i+m, j+n)K(m,n)

    离散卷积的计算

    
Input: 5x5
Kernel: 3x3
Stride: 1
Output: 3x3

    关键超参数

    超参数描述影响

    • 9.2 卷积的动机

    三个关键思想

  • 稀疏连接 (Sparse Connectivity)

    • - 每个输出只与局部输入连接

    - 减少参数量

  • 参数共享 (Parameter Sharing)

    • - 同一个滤波器在整个输入上共享

    - 平移不变性

  • 等变表示 (Equivariant Representations)

    • - 对输入的平移，特征图也平移

    - f(g(x)) = g(f(x))

    对比全连接层

    特性全连接卷积
    参数量O(n²)O(k² × c)
    平移不变无有
    局部结构无有

  • 旋转/尺度不变性

    10.1 循环网络的核心思想

    为什么要RNN？

    数据类型例子时间依赖
    图像静态图片无
    语音声谱图时间序列
    文本句子/文档上下文

    循环 vs 前馈

    前馈网络：

    • 每个输入独立处理
    • 无记忆能力

    循环网络：

    
h^{(t)} = f(h^{(t-1)}, x^{(t)}; \theta)
    • 隐藏状态携带历史信息
    • 参数在所有时间步共享

    10.2 展开计算图

    循环到前馈的展开

    
原始：h^{(t)} = f(h^{(t-1)}, x^{(t)})

展开：
h^{(0)} = f(x^{(0)})  # 初始
h^{(1)} = f(h^{(0)}, x^{(1)})
h^{(2)} = f(h^{(1)}, x^{(2)})
...

    参数共享的意义

    "如果在不同位置使用不同的参数，我们需要学习每个位置的规则。参数共享使模型能够泛化到不同长度的序列。"

    10.3 RNN的不同架构

    1. 序列到向量 (Many-to-One)

    
h^{(T)} = \text{RNN}(x^{(1)}, ..., x^{(T)})
y = \text{softmax}(Vh^{(T)} + c)

    应用：情感分类

    2. 向量到序列 (One-to-Many)

    
h^{(0)} = c  # 上下文向量
h^{(t)} = \text{RNN}(h^{(t-1)}, c)
y^{(t)} = \text{softmax}(Vh^{(t)} + c)

    应用：图像描述

    3. 序列到序列 (Many-to-Many, 相同长度)

    应用：帧级别分类

    4. 编码器-解码器 (Many-to-Many, 不同长度)

    
# 编码
h = \text{RNN}(x^{(1)}, ..., x^{(T)})  # 上下文向量

# 解码
h^{(t)} = \text{RNN}(h^{(t-1)}, y^{(t-1)})
y^{(t)} = \text{softmax}(Vh^{(t)} + c)

    应用：机器翻译

    10.4 梯度计算：BPTT

    通过时间反向传播 (Backpropagation Through Time)

    
def bptt(params, h_t, gradients):
    # 反向传播T步
    for t in reversed(range(T)):
        gradients += params['Wh'].T @ gradients_h
        gradients += params['Wx'].T @ gradients_x
        # 梯度裁剪
        gradients = clip(gradients)
    return gradients

    10.5 梯度消失与爆炸

    问题根源

    
\frac{\partial h^{(t)}}{\partial h^{(t-k)}} = \prod_{i=1}^{k} \frac{\partial h^{(t-i+1)}}{\partial h^{(t-i)}}

    梯度爆炸：

    • 梯度连乘 > 1
    • 解决方案：梯度裁剪

    梯度消失：

    • 梯度连乘 < 1
    • 解决方案：LSTM/GRU

    10.6 长短期记忆网络 (LSTM)

    LSTM核心：记忆单元

    
f_t = \sigma(W_f \cdot [h_{t-1}, x_t] + b_f)  # 遗忘门
i_t = \sigma(W_i \cdot [h_{t-1}, x_t] + b_i)  # 输入门
C_t = f_t  C_{t-1} + i_t  \tanh(W_C \cdot [h_{t-1}, x_t] + b_C)  # 候选记忆
o_t = \sigma(W_o \cdot [h_{t-1}, x_t] + b_o)  # 输出门
h_t = o_t * \tanh(C_t)  # 最终输出

    门的作用

    门作用直观理解
    遗忘门决定丢弃哪些记忆"忘记过去"
    输入门决定添加哪些新信息"记住现在"
    输出门决定输出什么"思考输出"

    LSTM如何解决梯度消失

    关键：记忆单元有恒等的梯度通道
    
C_t = f_t  C_{t-1} + i_t  \tilde{C}_t

    当 f_t ≈ 1 时，梯度可以直接流过。

    10.7 门控循环单元 (GRU)

    GRU公式

    
z_t = \sigma(W_z \cdot [h_{t-1}, x_t])  # 更新门
r_t = \sigma(W_r \cdot [h_{t-1}, x_t])  # 重置门
h_t = (1 - z_t)  h_{t-1} + z_t  \tanh(W \cdot [r_t * h_{t-1}, x_t])

    GRU vs LSTM

    特性LSTMGRU
    门数量32
    记忆单元有无
    参数量多少
    效果相当相当

    10.8 双向RNN

    核心思想

    
h_t = \text{RNN}_{\text{forward}}(x_1, ..., x_t)
h_t' = \text{RNN}_{\text{backward}}(x_T, ..., x_t)
y_t = \text{output}([h_t, h_t'])

    适用场景：

    Chapter 13: Linear Factor Models

    13.1 概述：什么是线性因子模型？

    线性因子模型是一类相对简单的概率模型，它通过线性变换和一个随机噪声来生成数据。这类模型是从简单概率模型向深度学习过渡的重要桥梁，其核心思想是：

    观测变量 x 由一组隐变量（因子）的线性组合加上噪声生成。

    数学形式为：

    $$p(x) = \int p(x|h)p(h)dh$$

    其中 $h$ 是隐变量（因子），$p(h)$ 通常选择简单的先验分布（如高斯或均匀分布），$p(x|h)$ 是条件分布。

    13.2 概率PCA（Probabilistic PCA）

    13.2.1 模型定义

    概率PCA是PCA的概率化版本，由Tipping和Bishop于1999年提出。假设：

    $$h \sim \mathcal{N}(0, I)$$

    $$x | h \sim \mathcal{N}(W h + \mu, \sigma^2 I)$$

    或等价地：

    $$x \sim \mathcal{N}(\mu, C)$$

    其中 $C = WW^T + \sigma^2 I$，$W \in \mathbb{R}^{d \times k}$ 是因子加载矩阵。

    13.2.2 与经典PCA的关系

    特征经典PCA概率PCA
    目标最小化重构误差最大化似然
    降维维度k可选可选
    参数估计SVDEM或闭式解
    生成能力无有（可生成新样本）
    不确定性建模无有（隐变量后验）

    核心洞察：当 $\sigma^2 \to 0$ 时，概率PCA退化为经典PCA。

    13.2.3 EM算法求解

    E步：$p(h|x)$（后验分布）

    $$p(h|x) = \mathcal{N}(\mu', (C'^{-1}))^{-1}$$

    其中：

    $$C' = (\sigma^2 I + W^TW)^{-1}$$

    $$\mu' = \frac{1}{\sigma^2}C'W^T(x - \mu)$$

    M步：更新参数 $W, \mu, \sigma^2$

    💡 批判性思考

    优势：

    • EM算法在大规模数据上比直接SVD更高效
    • 可以处理缺失数据
    • 提供完整的概率语义

    局限：

    • 假设高斯噪声可能不适合非高斯数据
    • 隐变量间的条件独立假设过于严格

    13.3 因子分析（Factor Analysis）

    因子分析本质上与概率PCA类似，但假设条件噪声协方差是对角矩阵而非各向同性：

    $$x | h \sim \mathcal{N}(Wh + \mu, D)$$

    其中 $D = \text{diag}(\sigma_1^2, \sigma_2^2, ..., \sigma_d^2)$ 是对角噪声协方差矩阵。

    与概率PCA的关键区别

    概率PCA因子分析
    噪声协方差$\sigma^2 I$对角矩阵 $D$
    适用场景各向同性噪声异方差噪声
    维度k选择通常k << dk << d

    13.4 独立成分分析（Independent Component Analysis, ICA）

    13.4.1 问题设定

    ICA假设观测数据是多个独立非高斯源的线性混合：

    $$x = As$$

    其中 $s$ 的各分量 $s_i$ 统计独立，且非高斯分布。

    13.4.2 信息论视角

    通过最大化非高斯性或最小化互信息来估计 $A$：

    $$W = A^{-1}$$

    常用的非高斯性度量包括：

    • 峰度（Kurtosis）：四阶累积量
    • 负熵（Negentropy）：基于信息熵
    • 互信息：$I(x) = \sum_j H(x_j) - H(x)$

    13.4.3 Infomax算法

    通过最大化神经网络的输出熵（或最小化互信息）来学习分离矩阵：

    $$\frac{\partial L}{\partial W} \propto (I - \phi(y)y^T)W$$

    其中 $\phi$ 是非线性激活函数（通常选为源的累积分布函数的导数）。

    💡 批判性思考

    ICA的局限：

    • 无法处理高斯源（高斯源的线性组合仍是高斯，无法分离）
    • 假设线性混合，对非线性混合无效
    • 需要估计独立成分的数量
    • 对噪声敏感

    与深度学习的对比：

    ICA是线性方法，无法捕捉非线性结构；深度自编码器可以学习更复杂的表示。

    13.5 慢特征分析（Slow Feature Analysis, SFA）

    核心思想

    时间慢特征假说：环境中的重要特征变化缓慢，而噪声和无关特征变化迅速。

    数学目标：对于时间序列 $x(t)$，找到非线性函数 $g(x)$ 使得：

    $$\min_f \langle (\dot{s}_i)^2 \rangle \quad \text{s.t.} \quad \langle s_i \rangle = 0, \text{Var}(s_i) = 1, \text{Cov}(s_i, s_j) = 0$$

    其中 $\dot{s}_i = \frac{\partial s_i(t)}{\partial t}$。

    应用场景

    • 神经科学：视皮层特征学习
    • 视频特征提取
    • 语音识别

    💡 跨领域联想

    SFA的思想与生物神经系统的时间整合特性高度一致——生物感知系统倾向于提取缓慢变化的特征，这可能是进化压力下的最优策略。从工程角度看，这也类似于低通滤波，但SFA通过学习实现，更为灵活。

    13.6 稀疏编码（Sparse Coding）

    13.6.1 模型定义

    稀疏编码假设数据通过稀疏线性组合生成：

    $$p(x|h) = \mathcal{N}(x; Wh + b, \beta^{-1}I)$$

    $$p(h_i) = \frac{\lambda}{2}e^{-\lambda|h_i|}$$

    先验 $p(h_i)$ 是Laplace分布，鼓励稀疏表示。

    13.6.2 学习算法

  • 推理阶段：给定 $x$，求解：

    • $$\hat{h} = \arg\min_h \frac{1}{2}\|x - Wh\|_2^2 + \lambda\|h\|_1$$

    这是LASSO问题，可用特征符号搜索（feature-sign search）等算法求解。

  • 字典学习：固定 $h$，更新 $W$：

    • $$\min_W \sum_i \|x^{(i)} - Wh^{(i)}\|_2^2 + \lambda\|h^{(i)}\|_1$$

    💡 批判性思考

    稀疏编码 vs. 神经网络：

    • 稀疏编码的推理是优化过程（需要迭代），而神经网络是前馈计算（速度快）
    • 但稀疏编码的可解释性更强——激活的基向量直接对应特征

    商业应用：

    • 图像去噪（基追踪去噪）
    • 图像修复
    • 特征提取用于分类

    13.7 本章小结与批判性总结

    核心要点

    模型生成方式隐变量先验特殊性质
    概率PCA$Wh + \epsilon$高斯条件共轭, EM可解
    因子分析$Wh + \epsilon$高斯异方差噪声
    ICA$As$非高斯独立通过非高斯性识别
    SFA非线性—时间慢变化
    稀疏编码$Wh + \epsilon$LaplaceL1稀疏诱导

    历史地位

    线性因子模型在深度学习历史上扮演了关键角色：

  • 过渡桥梁：从线性方法到非线性深度方法的认知铺垫
  • 概率框架：建立了概率建模的基本思维方式
  • RBM基础：RBM本质上是有约束的因子模型
  • 表示学习萌芽：隐变量即"表示"，这一思想延续到深度学习

    • 核心局限

    线性假设是双刃剑——既保证了可解释性和可证明性，又严重限制了模型的表达能力。所有线性因子模型都无法捕捉数据中的非线性结构。这正是需要深度学习方法的原因。

    Chapter 14: Autoencoders

    14.1 概述：从编码器到深度表示

    自编码器（Autoencoder, AE）是一种无监督学习方法，通过学习将数据压缩到低维表示，再从压缩表示重构原始数据。核心思想：

    学习一个恒等函数的近似，使得输出尽可能接近输入，但中间层（编码）的维度低于输入层。

    $$\mathcal{L}(x, g(f(x)))$$

    其中 $f$ 是编码器，$g$ 是解码器。

    14.2 欠完备自编码器（Undercomplete Autoencoder）

    当编码维度 $k$ 小于输入维度 $d$ 时，自编码器被迫学习数据的主要结构。

    14.2.1 线性欠完备AE与PCA的等价性

    若激活函数为线性，解码器也是线性，且损失为重构误差平方和，则欠完备AE等价于PCA。

    证明直觉：编码层相当于对输入进行了投影到由 $k$ 个主成分张成的子空间。

    14.2.2 非线性欠完备AE的表达能力

    一旦引入非线性激活函数，自编码器的能力远超PCA——它可以学习非线性流形的嵌入，这是PCA无法做到的。

    💡 关键洞察：PCA只能捕捉线性子空间，而自编码器可以捕捉非线性流形结构。这一区别在图像、语音等高维非线性的真实数据上至关重要。

    14.3 正则化自编码器

    欠完备不是唯一的正则化策略。当编码维度等于或超过输入维度时，需要其他形式的正则化。

    14.3.1 稀疏自编码器（Sparse Autoencoder）

    在重构损失上添加稀疏惩罚项：

    $$\mathcal{L} = \mathcal{L}_{\text{recon}} + \Omega$$

    其中 $\Omega = \lambda \sum_j |h_j|$ 或 $\Omega = \lambda \sum_j KL(\rho || \hat{\rho}_j)$。

    两种稀疏策略：

    • L1正则化：直接惩罚激活值的L1范数
    • KL散度惩罚：惩罚经验激活率 $\hat{\rho}_j$ 与目标稀疏率 $\rho$ 的KL散度

    $$KL(\rho || \hat{\rho}_j) = \rho \log \frac{\rho}{\hat{\rho}_j} + (1-\rho)\log\frac{1-\rho}{1-\hat{\rho}_j}$$

    14.3.2 去噪自编码器（Denoising Autoencoder, DAE）

    核心思想：向输入中添加噪声，训练网络重构原始无噪声输入。

    $$\mathcal{L} = \mathbb{E}_{x, \tilde{x} \sim p_{\text{data}}, q(\tilde{x}|x)} \|x - r(\tilde{x})\|^2$$

    其中 $q(\tilde{x}|x)$ 是损坏过程（通常为加性高斯噪声或随机掩码）。

    为何有效：

    去噪训练迫使自编码器学习数据的流形结构——因为它需要将损坏的样本"推回"到数据流形上。从信息论角度看，DAE学习的是数据分布的切空间结构。

    14.3.3 收缩自编码器（Contractive Autoencoder, CAE）

    通过惩罚编码对输入的敏感性：

    $$\Omega = \lambda \| \frac{\partial f}{\partial x} \|_F^2$$

    其中 $\|\cdot\|_F^2$ 是Frobenius范数（雅可比矩阵的）。

    效果：使编码对输入的小扰动不敏感，从而鼓励学习稳定的特征表示。

    14.3.4 对比：三种正则化策略

    策略正则化形式效果
    稀疏AE激活值L1/稀疏率KL主动抑制不重要的激活
    去噪AE输入损坏+重构学习流形结构
    收缩AE编码雅可比F范数抑制对输入扰动的敏感度

    14.4 随机自编码器（Stochastic Autoencoder）

    编码器和解码器的随机性

    编码器：$p_{\text{enc}}(h|x)$ — 通常是高斯分布 $q(h|x) = \mathcal{N}(h; \mu_{\text{enc}}(x), \sigma_{\text{enc}}^2(x)I)$

    解码器：$p_{\text{dec}}(x|h)$ — 通常是高斯或Bernoulli分布

    关键优势：随机编码/解码提供了更丰富的表达能力，允许模型捕捉条件分布的异方差结构。

    14.5 表示学习视角下的自编码器

    自编码器的核心价值不在于压缩，而在于学习好的数据表示。

    14.5.1 何时表示有用？

    以下场景中，从自编码器学到的表示特别有价值：

  • 聚类分析：好的表示使聚类边界更清晰
  • 分类任务：作为下游分类器的输入特征
  • 异常检测：正常样本的重建误差低，异常样本的重建误差高
  • 数据可视化：通过t-SNE等方法将编码降至2-3维进行可视化

    • 14.5.2 均匀分布假设

    好的表示应该具有分布均匀性——训练数据点在表示空间中的分布应尽可能均匀。如果某个区域的表示过于密集，说明模型没有充分利用表示空间。

    这一假设为信息瓶颈理论提供了直觉基础。

    14.6 预测稀疏分解（Predictive Sparse Decomposition, PSD）

    PSD是自编码器与稀疏编码的混合模型：

  • 使用一个神经网络编码器$h = f_{\text{enc}}(x)$（通常是前馈网络）
  • 解码器固定为字典 $D$，或也联合训练

    • $$\mathcal{L} = \|x - Dh\|^2 + \lambda \|h\|_1$$

    优势：推理速度极快（神经网络前馈），而稀疏编码需要迭代优化。

    14.7 自编码器的应用

    14.7.1 降维与可视化

    • MNIST、CIFAR-10等数据集的2D/3D可视化
    • 作为其他算法的预处理步骤

    14.7.2 异常检测

    • 重建误差 > 阈值 → 异常
    • 应用：欺诈检测、工业缺陷检测、网络入侵检测

    14.7.3 图像去噪与修复

    • DAE直接用于去除图像噪声
    • 填充图像缺失区域

    14.7.4 预训练

    ⚠️ 重要历史注记：在2006-2014年间，自编码器（或受限玻尔兹曼机）被广泛用于深度神经网络的贪心逐层预训练。但随着ReLU激活函数、更好的权重初始化和BN等技术的成熟，端到端联合训练成为主流，预训练不再是必要步骤。这是一个被主流实践"抛弃"但仍具理论价值的范式。

    14.8 本章小结与批判性总结

    核心洞察

    概念核心内容
    欠完备AE强制压缩 → 提取主要变化因子（与PCA等价于线性情况）
    稀疏AE通过惩罚激活不活跃 → 学习有意义的特征
    去噪AE从损坏中恢复 → 学习流形结构
    收缩AE抑制对输入敏感度 → 稳定表示
    PSD神经网络替代优化求解稀疏编码 → 快速推理

    批判性思考

    优势：

    • 完全无监督，不需要标签
    • 可以学习非线性流形嵌入
    • 可作为生成模型的基础

    局限：

    • 编码维度的选择缺乏理论指导
    • 没有显式的生成语义（只是重构，不是概率模型）
    • 评估表示质量困难（通常需要下游任务衡量）

    与生成模型的关系：

    自编码器本身不是生成模型，但通过马尔可夫链采样（从编码空间出发）或变分方法（VAE），可以扩展为生成模型。这将在后续章节（Chapter 19-20）中详细讨论。

    Chapter 15: Representation Learning

    15.1 概述：为什么表示重要？

    表示学习（Representation Learning） 的核心目标是自动从原始数据中学习出好的特征表示，而无需人工设计特征工程。

    "特征工程是机器学习的灵魂，但手工设计特征需要大量领域知识，且难以泛化。表示学习通过让模型自己学习特征，将人类从特征工程中解放出来。" — 这句话在深度学习时代仍然是核心信条。

    好表示的标准

    • 可分离性（Disentanglement）：不同维度表示数据的不同独立因素
    • 平滑性：表示的微小变化应导致数据的平滑变化
    • 可解释性：某些维度对应有意义的语义概念
    • 下游任务有效性：在分类、回归等下游任务上表现好

    15.2 贪心逐层预训练（Greedy Layer-Wise Pretraining）

    15.2.1 算法流程

  • 第一层：训练自编码器，将输入映射到第一层隐表示
  • 第二层：固定第一层，用原始输入（或第一层输出）训练第二层AE
  • 重复：逐层向上训练
  • 微调（Fine-tuning）：使用监督信号联合训练所有层

    • 15.2.2 理论基础

    为何有效？ Bengio等人（2007）的理论分析表明：

    - 每一层训练的目标是重构前一层产生的表示
    - 每一层的输入空间比原始输入空间更结构化（因为经过前一层处理）
    - 逐层训练降低了联合优化的难度

    关键洞察：每一层的输入是前一层产生的"伪标签"，而前一层已经捕捉了数据中的某种结构。这是一种自监督学习的早期形式。

    15.2.3 何时预训练有帮助？

    • 数据量较少时（正则化效果）
    • 无监督表示学习可行时
    • 优化困难时（深度网络难以从头训练）
    • 目标域有大量无标签数据时

    何时不必要？

    • 标注数据充足时
    • 使用ReLU + 好的初始化 + BatchNorm时
    • 任务相对简单时

    15.3 迁移学习（Transfer Learning）

    15.3.1 核心思想

    "学会打网球，有助于学会打羽毛球。" —— 知识从源域迁移到目标域。

    迁移学习利用在一个任务（源任务）上学到的表示，来帮助学习另一个任务（目标任务）。

    15.3.2 迁移学习的形式

    形式说明例子
    特征迁移固定特征提取器，训练新分类头ImageNet预训练模型
    微调联合训练所有层医疗图像分类
    多任务学习同时学习多个任务共享编码器
    领域适应源域和目标域分布不同Sim-to-real

    15.3.3 负迁移

    ⚠️ 警告：迁移学习并非总是有益的。如果源任务和目标任务的表示空间不兼容，迁移反而会损害目标任务的性能。这称为负迁移。

    负迁移的识别方法：

    • 对比迁移 vs. 从头训练
    • 分析表示空间的相似性

    15.4 半监督学习（Semi-Supervised Learning）

    15.4.1 定义

    半监督学习利用大量无标签数据和少量有标签数据来学习模型。

    15.4.2 表示学习与半监督学习的关系

    好的表示可以同时帮助：

  • 有标签数据的分类边界更清晰
  • 无标签数据的聚类结构更明显

    • 15.4.3 联合训练的两种途径

    方法1：纯无监督预训练 → 监督微调

    • 先用所有数据（包括无标签）做无监督预训练
    • 再用有标签数据做监督微调

    方法2：多任务学习

    • 共享编码器，同时优化无监督重构/生成目标和有监督分类目标

    💡 批判性思考

    伪标签（Pseudo-labeling）：

    • 用当前模型对无标签数据打标签
    • 将这些伪标签加入训练集
    • 迭代进行
    • 本质上是一种自训练（self-training）

    一致性正则化（Consistency Regularization）：

    • 对同一无标签样本施加不同的扰动
    • 要求模型输出相同
    • 这是当前半监督学习的主流方法（FixMatch, MixMatch等）的前身

    15.5 分布式表示（Distributed Representation）

    核心洞察

    分布式表示 vs. 聚类/原型表示：

    分布式表示聚类/原型表示
    表示方式多个维度同时激活单一类别标签
    可组合性维度组合 → 新概念无法组合
    泛化能力对未见概念可泛化只对见过的类有效
    例子词向量K-means聚类中心

    分布式表示的力量：

    $$v(\text{king}) - v(\text{man}) + v(\text{woman}) \approx v(\text{queen})$$

    词向量（word2vec）完美展示了分布式表示的组合性和零样本泛化能力。

    15.6 可解释性与解纠缠（Disentanglement）

    15.6.1 解纠缠表示的目标

    可解释的表示应对应数据的独立生成因素：

    • 图像：位置、光照、旋转、颜色等应分离
    • 语音：音调、语速、音色应分离

    15.6.2 β-VAE：解纠缠的变分方法

    $$\mathcal{L} = \mathbb{E}_q[\log p(x|h)] - \beta \cdot D_{\text{KL}}(q(h|x) || p(h))$$

    增大 $\beta > 1$ 会增强KL惩罚，鼓励后验接近先验（各分量独立），从而促进解纠缠。

    💡 跨领域联想

    神经科学视角：人脑的感知系统也表现出某种解纠缠特性——不同的神经元群体对不同的物理属性（如方向、颜色、运动速度）选择性响应。这暗示解纠缠可能不是单纯的技术目标，而是智能系统的一般性规律。

    15.7 课程学习（Curriculum Learning）

    核心思想

    "先学简单的概念，再学复杂的概念。" —— 这是人类学习的常见方式。

    课程学习按照从易到难的顺序呈现训练样本，类似于：

    • 儿童先学"猫"、"狗"，再学更抽象的概念
    • 数学教育从算术到代数到微积分

    实现方式

    • 人工设计课程（基于样本难度）
    • 自动课程（基于学习进度动态调整）
    • zorawski 课程（self-paced learning）

    15.8 本章小结与批判性总结

    核心要点

    主题核心内容
    贪心逐层预训练逐层无监督训练 → 监督微调（历史方法）
    迁移学习跨任务/领域复用表示
    半监督学习利用无标签数据增强表示
    分布式表示维度组合 → 组合泛化能力
    解纠缠独立生成因素的分离表示
    课程学习从易到难的学习顺序

    批判性思考

    预训练的"死亡"与"重生"：

    预训练在2012-2016年间是深度学习的标配，但随着以下进展，它逐渐变得不必要：
    1. ReLU + 好的初始化（Xavier/He）
    2. Batch Normalization / Layer Normalization
    3. 更大的标注数据集（ImageNet）
    4. 更强的优化器和学习率策略
    但2020年代，大模型的上下文学习（In-context Learning）某种意义上是预训练思想的"回归"——在大规模数据上预训练后，通过few-shot prompting适应下游任务。

    表示学习的未来：

    随着大语言模型（LLM）的发展，我们观察到涌现能力（Emergent Abilities）——当模型规模超过某个阈值后，突然具备之前没有的能力。这提示我们，规模（scale）本身可能比我们精心设计的表示学习算法更重要。

    Chapter 16: Structured Probabilistic Models for Deep Learning

    16.1 概述：从概率模型到结构化表示

    结构化概率模型（Structured Probabilistic Models） 是用图来描述概率分布中条件独立性关系的概率模型。这是连接浅层概率模型和深度概率模型的关键框架。

    "深度学习可以被视为一种结构化概率模型的层级化组合。每一层都可以看作一个变量集合，它们之间的条件独立性关系由网络架构决定。" — Goodfellow等

    16.2 有向模型 vs. 无向模型

    16.2.1 有向图模型（贝叶斯网络）

    使用有向无环图（DAG） 表示：

    $$p(x) = \prod_i p(x_i | \text{Pa}(x_i))$$

    特点：

    • 边有方向，表示因果关系（概念上）
    • 节点条件依赖于其父节点
    • 可以直接进行祖先采样（Ancestral Sampling）

    16.2.2 无向图模型（马尔可夫随机场/MRF）

    使用无向图表示：

    $$p(x) = \frac{1}{Z} \prod_i \phi_i(C_i)$$

    其中 $C_i$ 是极大团，$Z$ 是配分函数。

    特点：

    • 边无方向，不表示因果关系
    • 只编码"同现"关系（而非条件依赖）
    • 通常需要吉布斯采样或近似方法

    16.2.3 对比分析

    特征有向模型无向模型
    图结构有向无环（DAG）无向（可有环）
    边含义条件依赖（显式）软约束/同现（隐式）
    配分函数通常可解析计算通常 intractable
    推断难度通常较易通常较难
    采样方法祖先采样MCMC/Gibbs
    典型例子朴素贝叶斯, HMM, DBNMRF, RBM, CRF

    16.3 条件独立性与d-分离

    16.3.1 d-分离（D-separation）

    d-分离是判断有向图中条件独立性的图判定准则：

    给定集合 $S$，如果路径 $P$ 上的任意"碰撞节点"（$A \rightarrow B \leftarrow C$ 中的 $B$）或其后代均不在 $S$ 中，则 $P$ 被 $S$ 阻断。

    三种基本结构：

  • 链式：$A \rightarrow B \rightarrow C$，$B$ 阻断 $A$ 与 $C$
  • 分叉：$A \leftarrow B \rightarrow C$，$B$ 阻断 $A$ 与 $C$
  • 碰撞：$A \rightarrow B \leftarrow C$，$B$ 不阻断 $A$ 与 $C$（除非观测到 $B$）

    • 16.3.2 "解释逃离"（Explaining Away）

    碰撞结构是理解许多深度生成模型中后验分布复杂性的关键：

    $$p(h | v) \propto p(v | h)p(h)$$

    即使 $h_i$ 之间在先验下独立，观测到 $v$ 后它们通过 $v$ 形成活跃的碰撞路径，导致后验相关。

    16.4 能量函数模型（Energy-Based Models, EBM）

    无向模型的核心表示形式：

    $$p(x) = \frac{\exp(-E(x))}{Z}$$

    其中 $E(x)$ 是能量函数，$Z = \sum_x \exp(-E(x))$ 是配分函数。

    优势：任何非负函数都可以通过取负指数转化为概率分布。

    直觉理解：

    • 低能量 = 高概率
    • 能量函数定义了"偏好"的配置
    • 学习的目标是调整能量函数，使得真实数据能量低、虚假数据能量高

    16.5 配分函数与学习

    16.5.1 配分函数的困难

    $$p(x) = \frac{\tilde{p}(x)}{Z}, \quad Z = \sum_x \tilde{p}(x)$$

    对于高维数据，$Z$ 的计算通常是 intractable 的（指数复杂度）。

    16.5.2 对数似然梯度

    $$\nabla_\theta \log p(x) = \nabla_\theta \log \tilde{p}(x) - \nabla_\theta \log Z$$

    $$\nabla_\theta \log Z = \mathbb{E}_{x \sim p(x)}[\nabla_\theta \log \tilde{p}(x)]$$

    正相：增加数据点的非归一化概率

    负相：减少模型生成样本的非归一化概率

    ⚠️ 核心困难：负相期望的计算需要对 $p(x)$ 采样，而 $p(x)$ 本身是未知的——循环依赖问题。

    16.6 潜在变量与深度表示

    16.6.1 引入潜在变量的动机

    $$p(x) = \sum_h p(x|h)p(h)$$

    潜在变量 $h$ 提供了：

    • 数据的隐藏解释因素
    • 条件独立的结构（分层表示）
    • 更强的表达能力

    16.6.2 深度与层次表示

    多层潜在变量模型等价于深度神经网络：

    • 每一层表示一个抽象级别
    • 深层 = 更抽象的表示
    • 变分推断 ≈ 逐层推理

    16.7 实例：受限玻尔兹曼机（RBM）

    16.7.1 RBM结构

    RBM是两层无向二分图模型：

    • 可见层 $v$：观测数据
    • 隐层 $h$：潜在特征
    • 层内无边（"受限"于层内独立）

    能量函数：

    $$E(v, h) = -b^Tv - c^Th - v^TWh$$

    16.7.2 RBM的条件独立性

    关键性质：给定可见层，隐层各单元条件独立；反之亦然。

    $$p(h|v) = \prod_j p(h_j|v)$$

    $$p(v|h) = \prod_i p(v_i|h)$$

    这使得Gibbs采样和变分推断都变得高效。

    16.8 本章小结与批判性总结

    核心概念图谱

    
概率图模型
├── 有向模型（贝叶斯网络）
│   ├── 祖先采样
│   ├── 条件独立 → d-分离
│   └── 推断相对容易
└── 无向模型（MRF/EBM）
    ├── 能量函数
    ├── 配分函数 Z（通常 intractable）
    ├── 正相 + 负相学习
    └── MCMC采样

    历史意义

    图模型是连接概率论和深度学习的桥梁。它们提供了：1）表示不确定性和知识的语言；2）推理和学习的计算框架；3）设计与分析复杂系统的模块化思路。

    与深度学习的关系

    深度学习从图模型中继承的核心思想：

    • 层次化表示（多层潜变量）
    • 条件独立性假设（减少计算量）
    • 能量函数框架（统一判别和生成模型）

    Chapter 17: Monte Carlo Methods

    17.1 概述：为何需要蒙特卡洛方法？

    蒙特卡洛方法（Monte Carlo Methods） 是一类通过随机采样来近似计算确定性问题的方法。在概率模型中，它们用于：

    1. 近似期望：$\mathbb{E}_{p(x)}[f(x)] \approx \frac{1}{n}\sum_i f(x^{(i)})$
    2. 采样：从复杂分布 $p(x)$ 生成样本
    3. 配分函数估计：处理 intractable 的归一化常数

    拉斯维加斯算法 vs. 蒙特卡洛算法

    拉斯维加斯算法蒙特卡洛算法
    结果精确性精确（若完成）近似（有误差）
    运行时间随机固定预算
    典型应用精确搜索概率近似

    17.2 蒙特卡洛采样基础

    17.2.1 采样作为求和/积分的近似

    对于离散的：

    $$s = \sum_x p(x)f(x) = \mathbb{E}_p[f(x)]$$

    对于连续的：

    $$s = \int p(x)f(x)dx = \mathbb{E}_p[f(x)]$$

    蒙特卡洛估计：

    $$\hat{s}_n = \frac{1}{n}\sum_{i=1}^n f(x^{(i)}), \quad x^{(i)} \sim p(x)$$

    17.2.2 核心定理

    大数定律（LLN）：

    $$\lim_{n \to \infty} \hat{s}_n = s \quad \text{（几乎必然）}$$

    方差缩减：

    $$\text{Var}[\hat{s}_n] = \frac{\text{Var}[f(x)]}{n}$$

    中心极限定理（CLT）：

    $$\hat{s}_n \approx \mathcal{N}(s, \frac{\text{Var}[f(x)]}{n})$$

    这允许构建置信区间。

    17.3 重要性采样（Importance Sampling, IS）

    17.3.1 动机

    当无法从 $p(x)$ 直接采样时，引入提议分布 $q(x)$：

    $$\mathbb{E}_p[f(x)] = \int f(x)p(x)dx = \int f(x)\frac{p(x)}{q(x)}q(x)dx = \mathbb{E}_q\left[f(x)\frac{p(x)}{q(x)}\right]$$

    重要性权重：$w(x) = \frac{p(x)}{q(x)}$

    17.3.2 估计器

    $$\hat{s}_{IS} = \frac{1}{n}\sum_{i=1}^n f(x^{(i)})\frac{p(x^{(i)})}{q(x^{(i)})}, \quad x^{(i)} \sim q$$

    无偏估计。

    17.3.3 最优提议分布

    $$\text{Var}[\hat{s}_q] \propto \frac{|p(x)f(x)|^2}{|q(x)|^2}$$

    最优 $q^*(x) \propto |p(x)f(x)|$

    理论洞察：最优提议分布在 $|f(x)|$ 大（即 $p(x)f(x)$ 幅度大）的地方放置更多采样质量。

    17.3.4 维度灾难

    在高维空间中：

    • $p(x)$ 的动态范围极大
    • $q(x)$ 很难同时覆盖 $p(x)$ 的重要区域
    • 重要性权重方差爆炸（少数样本主导）

    💡 批判性思考

    重要性采样的致命弱点：

    当 $q(x)$ 在 $p(x)|f(x)|$ 大的区域概率接近0时，少数样本的权重会极大，导致估计器方差爆炸。这在高维空间几乎是必然发生的。解决方案：使用自归一化重要性采样（Self-Normalized IS），但会引入偏置。

    17.4 马尔可夫链蒙特卡洛（MCMC）

    17.4.1 马尔可夫链基础

    马尔可夫链：满足 $p(x^{(t+1)}|x^{(t)}, x^{(t-1)}, ...) = T(x^{(t+1)}|x^{(t)})$

    平稳分布（Stationary Distribution）：

    $$q(x) = \sum_{x'} q(x')T(x|x')$$

    如果细致平衡（Detailed Balance） 满足：

    $$q(x)T(x'|x) = q(x')T(x|x')$$

    则 $q$ 是平稳分布。

    17.4.2 从随机过程到采样

    核心思想：

  • 构建一个马尔可夫链，使其平稳分布 $q = p_{\text{model}}$
  • 从任意初始分布出发，运行链足够长时间
  • 链收敛后，样本近似来自 $p_{\text{model}}$

    • 17.4.3 收敛性理论

    Perron-Frobenius定理：

    • 转移矩阵的最大特征值为1
    • 对应的特征向量是平稳分布
    • 其他特征值的模 < 1 → 指数衰减收敛

    混合时间（Mixing Time）：链从初始分布收敛到平稳分布的时间。

    17.5 吉布斯采样（Gibbs Sampling）

    17.5.1 算法

    遍历每个变量（或变量块），从条件分布采样：

    $$x_i^{(t+1)} \sim p(x_i | x_{-i}^{(t)})$$

    17.5.2 为何有效？

    吉布斯采样的转移算子满足细致平衡，因为：

    $$p(x_{-i})p(x_i|x_{-i}) \cdot p(x_i'|x_{-i}) = p(x_{-i})p(x_i'|x_{-i}) \cdot p(x_i|x_{-i})$$

    优势：当条件分布易采样时（对某些变量），吉布斯采样特别有效。

    RBM中的吉布斯采样：

    • 给定 $v$，所有 $h_j$ 条件独立 $\rightarrow$ 整层可一次性采样
    • 给定 $h$，所有 $v_i$ 条件独立 $\rightarrow$ 整层可一次性采样
    • 这称为块吉布斯采样（Block Gibbs Sampling）

    17.6 混合模式困难（The Challenge of Mixing）

    17.6.1 问题本质

    好的采样需要快速混合——链应该能快速在不同模式间跳转。但这是深度生成模型中的核心困难。

    高能量屏障（Energy Barriers）：

    • 模式间被低概率区域分隔
    • 吉布斯采样只能进行局部移动
    • 跨越高能量屏障的概率 $\propto \exp(-\Delta E)$（指数衰减）

    17.6.2 可视化案例

    图17.1中的三种情况：

  • 独立高斯：混合快（局部移动即可）
  • 相关高斯：混合慢（需沿主轴方向移动）
  • 多峰分布：混合极慢（模式跳转困难）

    • 17.6.3 层表示与混合的关系

    关键洞察：深度生成模型中，浅层的条件分布 $p(h|x)$ 可能过于"确定"（熵低），导致从 $p(x|h)$ 采样时 $x$ 变化很小。这在训练RBM等模型时尤为突出——后验编码了太多信息，限制了采样多样性。

    17.7 tempered 采样：温度调节

    17.7.1 温度参数

    $$p_\beta(x) \propto \exp(-\beta E(x))$$

    • $\beta = 1$：原始分布
    • $\beta < 1$：更高温 → 更平坦（更容易混合）
    • $\beta > 1$：更低温度 → 更尖锐（更难混合）

    17.7.2 并行回火（Parallel Tempering）

    运行多个链在不同温度：

    • 高温链：快速混合，探索全局
    • 低温链：精确采样
    • 交换步骤：定期交换相邻温度链的状态

    这允许高温链发现的低能量区域被"传递"给低温链。

    17.7.3 tempered 过渡采样

    每次迭代：

  • 从高温分布采样（更容易跳转模式）
  • 逐步降温

    • 17.8 本章小结与批判性总结

    核心算法

    方法核心思想适用场景
    简单MCi.i.d. 采样求均值分布可采样
    重要性采样重加权采样可设计好提议分布
    吉布斯采样条件分布迭代采样条件分布易采样
    块吉布斯多变量同时采样分组条件独立
    并行回火多温度链交换多峰分布

    MCMC的工程现实

    burn-in问题：在链收敛之前丢弃样本。问题是：我们无法事先知道何时收敛。这是MCMC最不令人满意的方面之一。
    相关性样本：即使收敛后，连续样本仍高度相关。这降低了有效样本量——你需要运行更长时间。

    与深度学习的联系：

    • CD/PCD算法使用MCMC来逼近负相梯度（Chapter 18）
    • VAE和GAN使用MCMC思想进行采样
    • 生成模型的评估依赖MCMC生成样本

    Chapter 18: Confronting the Partition Function

    18.1 概述：配分函数的核心困难

    无向概率模型的核心挑战是配分函数 $Z$ 的 intractable 计算：

    $$p(x) = \frac{\tilde{p}(x)}{Z}, \quad Z = \sum_x \tilde{p}(x)$$

    对数似然梯度：

    $$\nabla_\theta \log p(x) = \nabla_\theta \log \tilde{p}(x) - \underbrace{\mathbb{E}_{x \sim p(x)}[\nabla_\theta \log \tilde{p}(x)]}_{\text{负相（难）}}$$

    18.2 正相与负相

    正相（Positive Phase）

    $$\nabla_\theta \log \tilde{p}(x) = \nabla_\theta \log \tilde{p}(x)$$

    效果：增加数据样本的能量（降低概率）——推高真实数据。

    负相（Negative Phase）

    $$\nabla_\theta \log Z = \mathbb{E}_{x \sim p(x)}[\nabla_\theta \log \tilde{p}(x)]$$

    效果：减少模型样本的能量——压低模型幻想的区域。

    💡 物理直觉

    "醒着时学习真实，梦着时消除幻想"。正相让我们更好地重构现实；负相防止我们沉溺于幻觉。睡眠/做梦的神经科学理论之一，就是大脑在进行类似的"负相学习"。

    18.3 朴素MCMC方法（Naïve MCMC）

    朴素方法：每个梯度步重新从随机初始化运行MCMC链。

    问题：

    • burn-in代价极高
    • 每个梯度步都需要burn-in → 不可行
    • 通常需要100+步burn-in

    18.4 对比散度（Contrastive Divergence, CD-k）

    18.4.1 核心思想

    "不要从随机初始化开始burn-in，而是从数据分布开始MCMC，然后只运行几步。"

    这利用了一个关键观察：数据分布本身已经接近模型分布的吸引域（尤其在训练早期）。

    18.4.2 CD-k算法

  • 从数据样本 $\tilde{x}^{(i)}$ 开始
  • 运行 $k$ 步吉布斯采样，得到 $\tilde{x}^{(i)}_k$
  • 用 $\tilde{x}^{(i)}_k$ 近似负相期望

    • 18.4.3 CD的偏差与优势

    偏差：CD是有偏估计——期望值不等于真实梯度。

    但偏差很小：Carreira-Perpiñan和Hinton（2005）证明，在RBM中偏差不足以阻止有效学习。

    计算优势：$k$ 通常只需1-20（而非100+），节省大量计算。

    💡 批判性思考

    CD为何有效（至少在早期）：

    训练初期，模型分布与数据分布差异大。此时从数据点出发，只需要几步就能找到附近模式。但随着训练推进，模型变得更精确，虚假模式（spurious modes）会远离数据点。此时CD的偏差增大。

    CD的致命缺陷——虚假模式问题：

    虚假模式（Spurious Modes）：在模型分布中存在，但在数据分布中不存在。CD从数据点出发，无法到达远离数据点的虚假模式。这些虚假模式会持续吸收模型的概率质量，导致模型性能下降。

    18.5 持久对比散度（Persistent Contrastive Divergence, PCD）

    18.5.1 核心思想

    "不要在每个梯度步重新初始化链，而是持久维护一组样本（fantasy particles），在每步训练后继续运行它们。"

    因为每步参数变化很小，样本只需要几步就能跟上分布的变化。

    18.5.2 PCD vs. CD

    CDPCD
    初始化数据分布上一轮的fantasy粒子
    链维护每步重置持久化
    虚假模式无法消除可以探索
    偏差有偏有偏（通常更小）
    方差低（正负相用相同数据点）高（独立采样）

    18.5.3 训练稳定性

    ⚠️ 警告：如果学习率过大或 $k$ 太小，PCD会不稳定。fantasy粒子可能在几步内"记忆"了旧模型而非当前模型。

    18.6 伪似然（Pseudolikelihood, PL）

    18.6.1 核心思想

    跳过配分函数：利用条件概率不涉及全局归一化的事实。

    $$p(a|b) = \frac{p(a,b)}{\sum_{a',c'}p(a',b,c')} = \frac{\tilde{p}(a,b)}{\sum_{a',c'}\tilde{p}(a',b,c')}$$

    18.6.2 伪似然估计

    $$\mathcal{L}_{\text{PL}} = \sum_i \log p(x_i | x_{-i})$$

    计算复杂度：每次只需要对单个变量求和/积分（而非全局归一化）。

    18.6.3 与真实似然的关系

    渐近一致性：当样本数 $n \to \infty$ 时，PL收敛到最大似然估计。

    在小样本时表现不同：

    • 对完整联合分布建模差（不适合密度估计）
    • 但对条件分布建模好（适合缺失值填充等任务）

    18.7 得分匹配（Score Matching, SM）

    18.7.1 核心思想

    不直接估计配分函数，而是比较对数密度对输入的梯度（称为"得分"，score）：

    $$\mathcal{L} = \frac{1}{2}\mathbb{E}_{p_{\text{data}}}\left[\|\nabla_x \log p_{\text{model}}(x;\theta)\|^2\right]$$

    这利用了一个关键观察：$\nabla_x \log Z(x) = 0$（因为 $Z$ 不依赖 $x$），从而绕过了配分函数。

    18.7.2 等价形式

    $$\tilde{\mathcal{L}}(x, \theta) = \sum_{j=1}^n \left[\frac{\partial^2}{\partial x_j^2}\log p_{\text{model}}(x;\theta) + \frac{1}{2}\left(\frac{\partial}{\partial x_j}\log p_{\text{model}}(x;\theta)\right)^2\right]$$

    注意：这里不需要知道 $p_{\text{data}}$！只需要采样数据点。

    18.7.3 局限

    ⚠️ 重要限制：得分匹配只适用于连续变量，且要求 $\log \tilde{p}$ 可微分。离散数据无法使用。

    18.8 噪声对比估计（Noise-Contrastive Estimation, NCE）

    18.8.1 核心思想

    将密度估计问题转化为二分类问题：

    $$p_{\text{joint}}(y=1|x) = \frac{p_{\text{model}}(x)}{p_{\text{model}}(x) + p_{\text{noise}}(x)}$$

    $$= \sigma(\log p_{\text{model}}(x) - \log p_{\text{noise}}(x))$$

    训练一个分类器区分"真实数据"和"噪声数据"。

    18.8.2 为何有效？

    当分类器达到最优时，它学到的决策边界等价于真实数据分布与模型分布的差异。这相当于隐式地估计了配分函数。

    18.8.3 NCE的深层洞察

    自对比估计（Self-Contrastive Estimation）：

    当噪声分布是模型自身的旧版本时，NCE的期望梯度等于最大似然的期望梯度。这提供了一个"无需显式配分函数"的MLE替代！

    💡 批判性思考

    NCE vs. GAN：

    NCE和GAN有深刻的联系！两者都是通过区分真实样本和生成样本来训练生成模型。区别在于：GAN的判别器是动态训练的（端到端），而NCE的噪声分布通常是固定的。

    18.9 配分函数估计

    18.9.1 重要性采样估计

    $$Z_1 = Z_0 \cdot \mathbb{E}_{x \sim p_0}\left[\frac{\tilde{p}_1(x)}{\tilde{p}_0(x)}\right]$$

    当 $p_0 \approx p_1$ 时有效。但高维场景下很难找到这样的 $p_0$。

    18.9.2 退火重要性采样（Annealed Importance Sampling, AIS）

    通过一系列中间分布桥接两个分布：

    $$Z_1/Z_0 = \prod_{j=0}^{n-1} \frac{Z_{\eta_{j+1}}}{Z_{\eta_j}}$$

    每个比值用重要性采样估计。

    典型应用：估计RBM等能量模型的配分函数。

    18.10 本章小结与批判性总结

    方法对比

    方法核心思想优点缺点
    CD从数据点短链采样快、低方差有偏、虚假模式
    PCD持久fantasy粒子消除虚假模式高方差、不稳定
    伪似然条件概率绕过Z归一化易处理全局建模差
    得分匹配比较score函数无需Z、无需采样只适连续
    NCE二分类转化可处理复杂模型需好噪声分布

    历史注记

    对比散度CD曾是训练RBM的主流方法（2002-2010），但随着深度学习工程实践的成熟，它的重要性下降。然而，CD/PCD的思想——用近似负相梯度训练生成模型——是后续变分推断和GAN等方法的理论先驱。

    Chapter 19: Approximate Inference

    19.1 概述：推断作为优化

    推断（Inference） 是计算后验分布 $p(h|v)$ 或其期望的过程。在深度生成模型中，这往往是 intractable 的。

    19.1.1 推断问题的困难来源

  • 配分函数 intractable（无向模型）
  • 后验分布 intractable（多峰、高维、复杂相关性）
  • 解释逃离（Explaining Away）：隐变量通过观测变量相互关联

    • 19.1.2 统一框架：证据下界（ELBO）

    对于任何分布 $q(h|v)$：

    $$\log p(v) = \mathcal{L}(v, \theta, q) + D_{\text{KL}}(q(h|v) || p(h|v;\theta))$$

    其中：

    $$\mathcal{L}(v, \theta, q) = \mathbb{E}_q[\log p(h,v)] + H(q)$$

    关键性质：

    • $\mathcal{L} \leq \log p(v)$（下界）
    • 当 $q(h|v) = p(h|v)$ 时取等号
    💡 核心洞察：推断 = 优化 $q$ 以最大化 $\mathcal{L}$；学习 = 优化 $\theta$ 以最大化 $\mathcal{L}$。两者统一在一个目标函数下。

    19.2 期望最大化（Expectation-Maximization, EM）

    19.2.1 算法流程

    E步：$q(h^{(i)}) \leftarrow p(h^{(i)} | v^{(i)}; \theta)$

    M步：$\theta \leftarrow \arg\max_\theta \sum_i \mathbb{E}_{q}[\log p(v^{(i)}, h; \theta)]$

    19.2.2 与变分学习的关系

    EM可以看作变分学习的特例，其中 $q$ 被约束为等于真实后验 $p(h|v)$。

    但真实后验 intractable！

    EM要求精确E步，这在大多数深度模型中不可行。

    19.3 MAP推理与稀疏编码

    19.3.1 MAP推理

    不是推断完整后验，而是找到最可能的配置：

    $$h^* = \arg\max_h p(h|v)$$

    19.3.2 作为近似推断的MAP

    将 $q$ 约束为Dirac分布 $q(h) = \delta(h - \mu)$：

    $$\mu^* = \arg\max_\mu \log p(v, h=\mu)$$

    这等价于MAP。

    ⚠️ 注意：Dirac分布的熵为负无穷，导致ELBO与 $\log p(v)$ 之间的KL散度是"无限大"的——约束太紧了。

    19.3.3 稀疏编码中的MAP

    稀疏编码的学习可以视为：

  • 推断步：用特征符号搜索等优化算法找最优 $h$（MAP）
  • 学习步：固定 $h$，用最小二乘更新字典 $W$

    • 19.4 变分推断与学习（Variational Inference and Learning）

    19.4.1 均值场近似（Mean Field Approximation）

    假设 $q$ 可分解：

    $$q(h|v) = \prod_i q(h_i | v)$$

    独立假设：每个隐变量独立。这使推断变得 tractable，但忽略了变量间的相关性。

    19.4.2 变分自由能

    $$\mathcal{L}(v, \theta, q) = \mathbb{E}_q[\log p(h,v)] + H(q)$$

    最大化 $\mathcal{L}$ 等价于：

    • 最小化 $D_{\text{KL}}(q(h|v) || p(h|v))$（推断）
    • 最大化 $\mathbb{E}_q[\log p(h,v)]$（学习）

    19.4.3 固定点迭代（Fixed-Point Iteration）

    对均场近似的最优更新：

    $$\tilde{q}_i(h_i) \propto \exp\left(\mathbb{E}_{q_{-i}}[\log \tilde{p}(v, h)]\right)$$

    迭代直到收敛。

    19.5 结构化变分推断（Structured Variational Inference）

    19.5.1 超越均场

    均场假设过于强（完全忽略相关性）。结构化变分推断允许 $q$ 具有任意的图结构：

    $$q(h|v) \text{ 有特定的因子分解}$$

    设计原则：$q$ 的结构应该捕捉 $p(h|v)$ 中的主要相关性。

    19.5.2 与神经网络的关系

    重大洞察：变分推断的固定点迭代展开为一个循环神经网络（RNN）！每个迭代步相当于RNN的一个时间步。这为学习型推断（Learned Inference）奠定了基础。

    19.6 连续隐变量的变分学习

    19.6.1 变分贝叶斯方法

    对连续变量，变分学习需要变分微积分（Calculus of Variations）：

    $$\frac{\delta \mathcal{L}}{\delta q(h)} = 0$$

    19.6.2 关键结果

    对于任意模型，最优近似后验满足：

    $$\log q^*(h_i | v) = \mathbb{E}_{q_{-i}}[\log \tilde{p}(v, h)] + \text{const}$$

    这告诉我们如何从模型中自动推导变分更新规则。

    💡 跨领域联想

    物理学视角：变分推断与统计物理中的平均场理论（Mean Field Theory）惊人地相似。平均场理论也是用可分解的近似分布来近似复杂系统的真实分布。两者的数学形式几乎相同。

    19.7 学习型近似推断（Learned Approximate Inference）

    19.7.1 核心思想

    不要用迭代优化来推断，而是训练一个神经网络来直接预测后验。

    $$q(h|v) \approx p_{\text{encoder}}(h|v; \phi)$$

    19.7.2 Wake-Sleep算法

    Sleep阶段：从模型 $p(h,v)$ 采样，训练识别网络 $q(h|v)$

    Wake阶段：从真实数据采样，训练生成网络 $p(h|v)$

    问题：Sleep阶段的样本来自当前模型，在训练早期模型很差 → 样本与真实数据差异大 → 识别网络学不好。

    19.7.3 变分自编码器（VAE）

    ⭐ 这是Chapter 19最重要的应用，虽然书中的VAE讨论在Chapter 20，但核心思想在此建立。

    VAE的关键创新：

  • 使用识别网络 $q_\phi(h|v)$（编码器）近似后验
  • 使用重参数化技巧（reparameterization trick） 使采样可导
  • 最大化ELBO $\mathcal{L}(\theta, \phi; v) = \mathbb{E}_q[\log p(v|h)] - D_{\text{KL}}(q(h|v)||p(h))$

    ELBO：统一的视角

    $$\log p(v) \geq \mathcal{L}(v, \theta, q) = \underbrace{\mathbb{E}_q[\log p(v|h)]}_{\text{重构}} - \underbrace{D_{\text{KL}}(q||p)}_{\text{先验正则化}}$$

    这个分解揭示了变分学习的双重目标：

    • 好的重构（让 $q$ 捕获后验的真实结构）
    • 接近先验（KL惩罚防止 $q$ 过度偏离 $p(h)$）

    批判性思考

    变分推断的近似误差：

    变分学习假设：好的近似后验 $\approx$ 真实后验 $\approx$ 能学习好模型。但这个链条可能断裂！模型参数可能调整到使得真实后验变得复杂（近似无法捕捉），而近似后验反而限制了模型的能力。这称为近似误差主导（Approximation Error Dominance）。

    识别网络 vs. 优化推断：

    优化推断学习型推断（识别网络）
    精度高（迭代到收敛）有限（网络容量）
    速度慢（多步迭代）快（单次前馈）
    可导性通常不可导端到端可导
    灵活性高（可对新模型用）低（需为每个模型训练）

    Chapter 20: Deep Generative Models

    20.1 概述：生成模型的版图

    深度生成模型（Deep Generative Models）结合了深度学习的表示学习能力与概率模型的生成语义。本章覆盖了2016年前的主要深度生成模型家族。

    20.2 玻尔兹曼机（Boltzmann Machines）

    20.2.1 定义

    玻尔兹曼机是全连接的（层内+层间）无向图模型：

    $$p(x) = \frac{\exp(-E(x))}{Z}$$

    能量函数（对二元变量）：

    $$E(v, h) = -v^TUv - h^TSh - v^TWh - b^Tv - c^Th$$

    20.2.2 学习问题

    • 配分函数 $Z$ intractable
    • 需要CD等近似方法
    • 全连接结构 → 计算极其昂贵

    20.3 受限玻尔兹曼机（Restricted Boltzmann Machines, RBM）

    20.3.1 结构

    • 两层（可见/隐层）
    • 层内无边（"受限"）
    • 层间全连接

    20.3.2 条件独立性

    关键性质：

    $$p(h|v) = \prod_j p(h_j|v), \quad p(v|h) = \prod_i p(v_i|h)$$

    条件分布（对二元RBM）：

    $$p(h_j=1|v) = \sigma(c_j + v^TW_{:,j})$$

    $$p(v_i=1|h) = \sigma(b_i + W_{i,:}h)$$

    20.3.3 训练

    因为条件分布 tractable，可以使用：

    • 对比散度（CD）
    • 伪似然
    • 变分推断

    历史意义：RBM是深度学习早期复兴的核心——它证明了可以用无监督逐层训练来初始化深度网络。

    20.4 深度信念网络（Deep Belief Networks, DBN）

    20.4.1 结构

    DBN是多层有向+无向混合的模型：

    • 顶层：无向（近似一个RBM）
    • 底层到顶层：有向（sigmoid置信网络）

    20.4.2 推理与学习

    推理：顶层到底层的近似推理，通过激活底层的条件分布。

    学习：逐层贪心训练：

  • 训练第一层（RBM）
  • 固定第一层，用其输出训练第二层
  • ...

    • 贡献：证明了深度网络可以被有效训练（打破"深度网络无法训练"的偏见"）。

    20.5 深度玻尔兹曼机（Deep Boltzmann Machines, DBM）

    20.5.1 完全无向的深度模型

    DBM是完全无向的多层玻尔兹曼机：

    $$p(x) = \frac{1}{Z}\exp(-E(x))$$

    多层结构提供了更强的表示能力。

    20.5.2 推断困难

    问题：DBM同时面临两个困难：

  • 配分函数 intractable
  • 后验分布 intractable（多层 → 强相关性）

    • 20.5.3 变分推断用于DBM

    使用均场变分推断：

    $$q(h) = \prod_l \prod_j q(h_j^{(l)})$$

    迭代更新直到收敛。

    20.5.4 训练策略

  • 贪心逐层预训练：先将每层训练为RBM
  • 联合微调：用wake-sleep或变分学习联合优化

    • 20.6 用于实值数据的玻尔兹曼机

    20.6.1 高斯-伯努利RBM

    对实值可见数据：

    $$p(v|h) = \mathcal{N}(v; Wh + b, \sigma^2 I)$$

    这允许RBM直接处理实值输入（如图像像素）。

    20.7 卷积玻尔兹曼机

    将卷积结构引入玻尔兹曼机：

    • 共享权重
    • 空间局部连接
    • 更适合图像数据

    20.8 用于结构化输出的玻尔兹曼机

    扩展BM处理结构化输出（如序列、图像标签等）。

    20.9 通过随机操作的反向传播

    20.9.1 动机

    深度生成模型中包含随机层（输出随机变量），无法直接反向传播。

    20.9.2 梯度估计方法

    方法思想方差
    REINFORCE策略梯度高
    变分推断使用识别网络降低方差中
    重新参数化确定变换 + 随机采样低

    重新参数化技巧（Reparameterization Trick）：

    $$h = \mu + \sigma \cdot \epsilon, \quad \epsilon \sim \mathcal{N}(0,I)$$

    将随机性移到独立的 $\epsilon$，使梯度可以通过 $\mu, \sigma$ 反向传播。

    20.10.3 变分自编码器（Variational Autoencoder, VAE）

    ⭐ 本章最重要的模型

    核心架构：

    • 编码器（识别网络）：$q_\phi(h|v)$
    • 解码器（生成网络）：$p_\theta(v|h)$
    • 先验：$p(h) = \mathcal{N}(0,I)$

    目标函数（ELBO）：

    $$\mathcal{L}(\theta, \phi; v) = \mathbb{E}_{q_\phi(h|v)}[\log p_\theta(v|h)] - D_{\text{KL}}(q_\phi(h|v) || p(h))$$

    重参数化：

    $$h = \mu_\phi(v) + \sigma_\phi(v) \cdot \epsilon, \quad \epsilon \sim \mathcal{N}(0,I)$$

    20.10.4 生成对抗网络（Generative Adversarial Networks, GAN）

    核心思想：同时训练两个网络——

    • 生成器 $G$：生成假样本
    • 判别器 $D$：区分真假样本

    两人零和博弈：

    $$\min_G \max_D \mathbb{E}_{x \sim p_{\text{data}}}[\log D(x)] + \mathbb{E}_{z \sim p_z}[\log(1-D(G(z)))]$$

    深度学习的哲学启示

    1. 层级表示的普遍性

    从概率图模型到神经网络，层级化组合是表示复杂分布的核心策略。每一层增加一个抽象级别，组合性使系统可以表达指数级复杂的函数。

    2. 近似与精确的权衡

    几乎所有深度生成模型的核心都是近似：近似后验、近似配分函数、近似采样。追求完美精确往往不可行，接受"足够好"的近似是工程智慧。

    3. 对抗训练的深远影响

    GAN的核心洞察——通过竞争学习生成——远超出了图像生成本身。这一思想影响了强化学习、知识蒸馏甚至优化理论。

    4. 从显式概率到隐式概率

    自回归模型和GAN代表了从"显式写出 $p(x)$"到"隐式定义生成过程"的转变。这大大扩展了可建模的分布范围。

    5. 表示学习的终极问题

    什么是好的表示？
    - 可分离性（Disentanglement）
    - 分布均匀性（Uniformity）
    - 下游任务有效性（Downstream utility）
    - 生成能力（Generative capability）
    这些标准往往相互竞争，实际中需要权衡。
